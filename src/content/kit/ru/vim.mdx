# Аддон DeepWorkPlan Vim

**DeepWorkPlan Vim** — терминальный редактор Deep Work Plan: конфигурация Neovim (это сам редактор, а не файл репозитория), которая ставит рабочие поверхности методологии на расстоянии одного нажатия клавиши. Пока остальные записи набора устанавливают harness в репозиторий, этот аддон оснащает человека — и любого агента, управляющего Neovim в headless-режиме, — редактором, который говорит на DWP изначально.

Требуется **Neovim 0.12 или новее**, работает на **macOS и Linux** (для Windows есть документированный ручной путь), лицензия — **GPL-3.0**: свободно использовать, изучать и изменять.

## Что он добавляет

| # | Возможность | Что делает | Сочетание |
|---|---------|--------------|---------|
| F1 | **Генерируемый индекс команд** | Весь редактор списком: каждая команда со своим сочетанием и описанием в одну строку; генерируется из живой конфигурации, поэтому индекс не расходится с редактором. | `SPC h h` |
| F2 | **Жесты в духе VS Code** | Выделить всё, скопировать и yank в буфер обмена на аккордах, которые мышечная память уже знает. | `<C-a>`, `y`, `<leader>y` |
| F3 | **Обозреватель Deep Work Plan** | Открывает план, который ведёт репозиторий, — задачи, гейты и состояние завершения — не покидая редактор. | `SPC P` |
| F4 | **Просмотрщик Markdown** | Читает Markdown так, как это делают агенты: отрисованный предпросмотр или исходник для точности копирования. | `SPC m p`, `SPC m r` |
| F5 | **Установщик одной строкой** | Согласие прежде всего: `install.sh` для macOS и Linux; документированный ручной путь покрывает Windows. | `curl -fsSL https://deepworkplan.com/vim/install.sh \| bash` |

## Установка

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

<VimInstall lang="ru" />

Установщик **consent-first**: существующий чужой конфиг Neovim никогда не перезаписывается. При запуске через канал без терминала он прерывается с инструкциями, ничего не трогая; в интерактивном режиме спрашивает, прежде чем отодвинуть существующий конфиг. Плагины устанавливаются headless при первом запуске — без танцев с выходом и повторным открытием.

Windows не является целью `curl | bash`. Документированный ручной путь (winget плюс Git Bash или WSL) описан в README репозитория.

## Когда прибегать

| Сигнал | Действие |
|--------|--------|
| Разработчик живёт в терминале и ведёт репозиторий по плану | **Предложить** аддон |
| Долгая DWP-работа, где обозреватель планов (`SPC P`) держит состояние на виду | **Порекомендовать** |
| Редактор разработчика уже настроен и не подлежит обсуждению | **Пропустить** — аддон опционален по замыслу |
| Команда только на Windows без WSL | **Пропустить** или указать документированный ручной путь |
