# dwp-execute

Выполнение существующего Deep Work Plan.

<CmdExecute lang="ru" class="not-prose my-8" />

## Что он делает

`dwp-execute` выполняет существующий план задача за задачей. Он читает весь план, выполняет каждую задачу по порядку, обновляет `PROGRESS.md` и отмечает статус завершения каждой задачи.

## Использование

```
/dwp-execute
/dwp-execute [plan]
/dwp-execute [plan] trust
```

## Поведение

1. Прочитать весь план перед началом.
2. `ledger.py ready` & `ledger.py start` -> Выполнять задачи по порядку.
3. `ledger.py gate` -> `observed` evidence; Обновлять `PROGRESS.md` после каждой задачи.
4. `parallel_safe` delegation; Точно отмечать статус задачи.
5. `ledger.py complete` & Final Review; Останавливаться и спрашивать при блокировке.

## Псевдонимы

- `dwp:execute`
