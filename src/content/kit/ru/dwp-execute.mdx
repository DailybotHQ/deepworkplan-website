# dwp-execute

Выполнение существующего Deep Work Plan задача за задачей.

<CmdExecute lang="ru" class="not-prose my-8" />

## Что он делает

`dwp-execute` выполняет существующий план задача за задачей через детерминированный слой записей. Он определяет целевой план, оценивает зависимости, выполняет каждую задачу в объявленном порядке, прогоняет шлюзы валидации и фиксирует неизменяемый прогресс.

## Использование

```
/dwp-execute                     # execute latest plan
/dwp-execute [plan]              # by exact folder, id, or slug
/dwp-execute [plan] trust        # unattended execution without per-task prompts
```

## Режимы

- **Управляемый (по умолчанию):** запрашивает подтверждение между задачами, позволяя проверять доказательства и решения на каждой границе задачи.
- **Trust (`auto`):** добавленный `trust` последовательно выполняет допустимые задачи до завершения без пауз на рутинные подтверждения и останавливается только при реальной блокировке (классы эскалации C1–C7).

## Поведение

1. **Определение плана:** находит план по точному имени папки, числовому ID, уникальному slug или `latest` (план с наибольшим числовым ID).
2. **Цикл реестра:** запускает `ledger.py ready` для оценки DAG зависимостей и инвариантов, `ledger.py start` для проверки предусловий и `ledger.py gate` для выполнения команд валидации и выпуска доказательств `observed`.
3. **Защищённое завершение:** `ledger.py complete` применяет контроль против прогонов с нулём тестов, свежую оценку инвариантов и локальные для задачи решения о навыках и документации.
4. **Делегирование внутри плана:** задачи, помеченные `parallel_safe` в контрактах v7, могут делегироваться субагентам через headless-транспорт (`ak run` в worktree) или интерактивный транспорт (панель `herdr`). Результаты остаются `asserted`, пока их не подтвердит исполнитель шлюзов плана.
5. **Проверки ёмкости:** на границах задач перед диспетчеризацией оценивает оставшийся запас учётной записи.
6. **Final Review:** завершается обязательной заключительной задачей из пяти частей (проверка безопасности с обязательным локальным ревью, валидация итогового состояния, сверка навыков, сверка документации, завершение).

## Псевдонимы

- `dwp:execute`
