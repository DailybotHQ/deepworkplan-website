# dwp-status

Отчёт о статусе Deep Work Plan без выполнения.

<CmdStatus lang="ru" class="not-prose my-8" />

## Что он делает

`dwp-status` резюмирует прогресс плана, ничего не меняя. Он отчитывается о завершённых, выполняемых и ожидающих задачах.

## Использование

```
/dwp-status
/dwp-status [plan]
```

## Поведение

1. 4 lifecycle dimensions (format, materialization, review, progress); Прочитать план и `PROGRESS.md`.
2. Резюмировать завершённые задачи.
3. Резюмировать выполняемые задачи.
4. Resource envelope & blockers (C1–C7); Резюмировать ожидающие задачи.
5. Delegations observation; Отчитаться, ничего не изменяя.

## Псевдонимы

- `dwp:status`
