# dwp-resume

Возобновление прерванного Deep Work Plan по долговременным записям.

<CmdResume lang="ru" class="not-prose my-8" />

## Что он делает

`dwp-resume` безопасно продолжает прерванный план только по артефактам рабочего пространства, без повторного выполнения. Он детерминированно восстанавливает состояние из `journal.ndjson` и `contract.json`, читает ожидающие пакеты передачи и продолжает с первой незавершённой задачи.

## Использование

```
/dwp-resume [plan]
```

## Поведение

1. **Чтение записей:** изучает `contract.json` и `journal.ndjson` в `.dwp/plans/PLAN_<id>_<slug>/`.
2. **Проекция состояния:** запускает `ledger.py project`, чтобы детерминированно заново построить `state.json` из журнала, допускающего только добавление. Расхождения разрешаются в пользу журнала.
3. **Приём передачи:** проверяет наличие ожидающих пакетов передачи роя (`dwp-handoff-v1`), чтобы восстановить намерения в процессе выполнения, непроверенные шлюзы и открытые запросы пиров.
4. **Проверка стыка:** проверяет состояние git и перед возобновлением прогоняет smoke-проверки затронутых поверхностей.
5. **Продолжение:** выполняет первую открытую задачу через стандартный цикл выполнения. Устаревшие планы v5 продолжают работать по записанному потоку `PROGRESS.md` без принудительной миграции.

## Псевдонимы

- `dwp:resume`
