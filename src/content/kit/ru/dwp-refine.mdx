# dwp-refine

Доработка существующего Deep Work Plan.

<CmdRefine lang="ru" class="not-prose my-8" />

## Что он делает

`dwp-refine` изменяет существующий план. Он может добавлять, удалять или переупорядочивать задачи, сохраняя завершённую работу и обновляя таблицу задач.

## Использование

```
/dwp-refine [plan]
```

## Поведение

1. Прочитать существующий план.
2. Добавить, удалить или переупорядочить задачи.
3. Сохранить завершённую работу.
4. Обновить таблицу задач.
5. Зафиксировать, что изменилось и почему.

> После обновления навыка существующие планы сохраняют записанное поколение. Миграция никогда не выполняется автоматически: прежнее завершение из трех задач можно явно перевести в сохраненный формат Final Review для v5; план v5 переходит на v6 только после явного запроса и предварительного просмотра. План v6 сохраняет своё поколение и выполняется без изменений; новые планы используют текущее поколение v7, и план v6 никогда не переводится на v7 неявно.

## Повышение Lite-плана до Full

`/dwp-refine promote {plan_name}` переключает авторитетное представление Lite-плана с встроенных в README записей задач на файлы по каждой задаче, сохраняя завершённую работу и идентификаторы задач без изменения объёма. Повышение затрагивает только представление — оно никогда не вызывает execute. Full-планы не понижаются автоматически обратно до Lite.

## Псевдонимы

- `dwp:refine`
