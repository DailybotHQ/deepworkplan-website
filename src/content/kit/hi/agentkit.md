# Agentkit addon

हर टर्मिनल कोडिंग एजेंट के पास सत्र जारी रखने के अपने फ़्लैग, दूसरे खाते को अलग रखने का अपना तरीका, अपना headless मोड और अनुमति प्रॉम्प्ट छोड़ने का अपना स्विच होता है। **[coding-agents-kit](https://github.com/DailybotHQ/coding-agents-kit)** इन सभी के ऊपर एक ही कमांड सतह रखता है: `ak <kind> [@profile]`।

यह ऐडऑन इस kit को **DWP v7** (पैक `v7.6.3`) में **headless** प्रत्यायोजन ट्रांसपोर्ट के रूप में एकीकृत करता है। यह वैकल्पिक है: इसके बिना हर कार्य वर्तमान सत्र में ही चलता है, ठीक पहले की तरह। kit स्वयं एक MIT उत्पाद है जो Deep Work Plan के बिना भी काम करता है।

## kit आपको क्या देता है

- **हर CLI के लिए एक व्याकरण।** `ak claude`, `ak codex`, `ak cursor`, `ak opencode`, `ak pi`, `ak cline` और `ak grok`, साथ ही प्रदाता वेरिएंट (GLM, Azure, xAI), एक जैसे सत्र फ़्लैग के साथ: `-c` जारी रखता है, `-r <id>` फिर से शुरू करता है।
- **प्रोफ़ाइल।** `ak claude @work` एक दूसरे खाते को उसकी अपनी home में चलाता है, पहले खाते से अलग।
- **headless रन।** `ak run <kind> -- "<prompt>"` एक प्रॉम्प्ट को गैर-इंटरैक्टिव रूप से चलाता है और एक प्रलेखित exit code लौटाता है, वैकल्पिक रूप से एक JSON ऑब्जेक्ट के रूप में।
- **एक doctor।** `ak doctor --json` बताता है कि कौन-से CLI इंस्टॉल हैं, कौन-सी प्रोफ़ाइलें हैं, और सेट की गई कुंजियों के नाम — उनके मान कभी नहीं।
- **सत्यापित इंस्टॉल।** `ak install <cli>` किसी अनुपस्थित CLI को उसके विक्रेता के आधिकारिक चैनल से एक पिन किए गए संस्करण पर इंस्टॉल करता है, जिसे एक पिन किए गए sha256 या npm रजिस्ट्री की integrity से जाँचा जाता है।
- **परिचित नाम।** दो alias presets, जो तब तक बंद रहते हैं जब तक आप उन्हें चालू न करें: `classic` (`claudex`, `codexx`, `cursorx`, `opencodex`, `pix`, `clinex`, `grokx`) और `providers` (`claude-glm`, `codex-azure`, `codex-xai`, `pi-glm`, …), जिनमें से हर एक एक `ak <kind>` है।

## खाते, कोटा और खाता चुनना

kit आपके हर लॉगिन या कुंजी को एक **खाता** मानता है: एक CLI × एक प्रोफ़ाइल। `@default` (या `@1`) CLI का अपना home है; `@2`, `@work` या `@client-x` अलग लॉगिन हैं, हर एक प्रोफ़ाइल रूट के नीचे अपनी डायरेक्टरी में, जो साथ-साथ चलते हैं। `ak profiles` उन्हें उनकी लॉगिन स्थिति और उनकी कुंजियों के नामों के साथ सूचीबद्ध करता है; `ak profiles --json` टूल्स को वही सूची देता है (स्कीमा `profiles-v1`)। `v0.5.1` से यह बताता है कि Claude Code का token वास्तव में कहाँ है — `file`, `keychain` (macOS), `none` या `unknown` — केवल उपस्थिति के आधार पर, secret को कभी पढ़े बिना, और Linux पर, किसी container में या Linux होस्ट पर, Cursor लॉगिन पहचाना जाता है। `v0.5.2` से, `AGENTKIT_DEFAULT_PROFILE_<CLI>` उस खाते का नाम देता है जिसे बिना तर्क वाला `ak <cli>` उपयोग करता है (positional `@profile` फिर भी प्राथमिकता पाता है), और इसी तरह एक dev container वह होस्ट खाता चुनता है जिसे वह साझा करता है। `v0.5.3` से, जब किसी दूसरी मशीन के साथ साझा की गई Codex home ऐसे background daemon को दर्ज करती है जो इस मशीन पर नहीं है, तो `ak codex` `--no-daemon` जोड़ता है।

`ak usage` उन सभी खातों का कोटा और उपयोग दिखाता है जिन्हें kit देख सकता है, हर खाते और प्रोफ़ाइल के लिए एक पंक्ति: Claude Code सब्सक्रिप्शन (5 घंटे, साप्ताहिक और प्रति-मॉडल विंडो), ChatGPT से Codex लॉगिन और Z.AI कोडिंग प्लान की कुंजियों के लिए लाइव; Cursor, Grok, xAI और Azure OpenAI कारण के साथ `n/d` दिखाते हैं। यह केवल पढ़ता है: यह कभी लॉगिन रीफ़्रेश नहीं करता, कभी टोकन प्रिंट नहीं करता और कभी किसी प्रोफ़ाइल के भीतर कुछ नहीं लिखता। `--json` टूल्स को वही सूची देता है (स्कीमा `usage-v1`)। उपयोग के endpoint विक्रेताओं के आंतरिक और अनौपचारिक हैं।

`ak pick <kind>` वही पंक्तियाँ पढ़ता है और सबसे अधिक गुंजाइश वाले खाते का नाम बताता है। `--count N` अधिकतम N खाते लौटाता है, सबसे अच्छा पहले; `--exclude @<profile>` किसी व्यस्त खाते को बाहर रखता है; `--model` एक मॉडल की साप्ताहिक विंडो गिनता है; `--need 5h:40` उतनी गुंजाइश के बिना चुनने से इनकार करता है। `--json` स्कीमा `pick-v1` देता है।

```bash
ak usage                   # हर खाते और प्रोफ़ाइल का कोटा
ak pick claude --count 3   # सबसे अधिक गुंजाइश वाले तीन Claude खाते
ak claude @work --trust-cwd  # दूसरा खाता, फ़ोल्डर पहले से trusted
ak profiles --json         # profiles-v1, टूल्स के लिए
ak setup verify            # क्रमबद्ध जाँचें, हर एक अपने सुधार कमांड के साथ
```

`--trust-cwd` (या `AGENTKIT_TRUST_CWD=1`) उस फ़ोल्डर को पहले से trusted कर देता है जिसमें एजेंट शुरू होता है, ताकि Claude Code और Codex अपनी फ़ोल्डर-trust स्क्रीन के बिना खुलें। `ak setup probe | verify | docker` केवल-पढ़ने वाला सहायक है, जिसे `agentkit-setup` skill चलाता है: यह मशीन की जाँच करता है, इंस्टॉल को सत्यापित करता है और tag पर पिन की गई, सत्यापित container रेसिपी बनाता है।

## कई एजेंट, कई खाते

`agentkit-orchestrate` skill (`ak --skill orchestrate`) एक एजेंट को काम को कई एजेंटों, खातों और विक्रेताओं में बाँटना सिखाता है: बैच से पहले एक `ak usage`, खाते चुनने के लिए `ak pick --count N`, हर खाते के लिए एक प्रतिनिधि, हर परिणाम पर रिपॉज़िटरी का अपना गेट, और जब कोई खाता सीमा पर पहुँचे तो अगले खाते पर failover। kit देखता है, गणना करता है और चलाता है; वह कभी शेड्यूल नहीं करता। निर्णय लीड करता है — आप, या वह एजेंट जिससे आपने कहा — केवल आपके अपने खातों का उपयोग करते हुए और हर विक्रेता की शर्तों के भीतर।

लंबी, इंटरैक्टिव लेन के लिए, हर लेन अपने खाते पर एक [Herdr](/kit/herdr) पेन में चलती है। पद्धति का अध्याय [कई एजेंट चलाना](/methodology/06-orchestration) पूरे मॉडल का वर्णन करता है: एक लीड और उसकी लेन, हेडरूम से चुने गए खाते, herdr-peers समन्वय, और हर रिपॉज़िटरी के लिए एक ब्रांच और एक रिलीज़।

## इंस्टॉल

```bash
git clone --branch v0.6.0 https://github.com/DailybotHQ/coding-agents-kit && ./coding-agents-kit/install.sh
ak doctor
```

आवश्यकताएँ: macOS या Linux पर `bash`, और `python3` 3.9 या नया; और कुछ नहीं। Windows `install.ps1` का उपयोग करता है। `v0.6.0` पिन करें: `v0.2.0` और `v0.2.1` समर्थित नहीं हैं। किसी रिलीज़ को उसके `SHA256SUMS` asset से सत्यापित करें।

| मद | मान |
|---|---|
| उत्पाद | `DailybotHQ/coding-agents-kit`, tag `v0.6.0`, इंटरफ़ेस 1 |
| रजिस्ट्री कुंजी | `.dwp/config.json` में `agentkit` |
| ट्रांसपोर्ट | headless: हर प्रत्यायोजित एजेंट के लिए एक समर्पित git worktree में एक `ak run` |
| प्रदान करता है | `subagents`, `cancel_children`, `model_routing` |
| आवश्यकता | योजना अनुबंध की `agent_delegation` अनुमति |

## डिफ़ॉल्ट रूप से स्वायत्तता, ऐसे opt-out के साथ जो हमेशा प्रभावी रहता है

`v0.2.0` से, `ak <kind>` हर एजेंट को **स्वायत्तता** में लॉन्च करता है: यह CLI का अपना स्वायत्तता फ़्लैग जोड़ता है, जो केवल kit की `providers.toml` में रखा जाता है। स्वायत्तता डिस्पोज़ेबल या sandboxed परिवेशों के लिए है, जैसे एक development container।

**opt-out हमेशा प्रभावी रहता है**: किसी एक कमांड पर `--ask`, या environment में या kit की env फ़ाइल में `AGENTKIT_PERMISSIONS=ask`, फ़्लैग को दबा देता है, तब भी जब वही कमांड `--auto` कहे। opt-out किया गया सत्र यह opt-out उन एजेंटों तक पहुँचाता है जिन्हें वह शुरू करता है। होस्ट पर opt-out सेट करें।

ऐडऑन कोई स्वायत्तता फ़्लैग नहीं लिखता और कभी `--auto` पास नहीं करता। जब कोई योजना opt-out दर्ज करती है, तब यह `--ask` पास करता है। होस्ट पर `agent_delegation` अनुमति देने वाली योजना ऐसे स्वायत्त प्रत्यायोजित एजेंटों को स्वीकार करती है जो अपने worktree तक सीमित हैं, और worktree कोई sandbox नहीं है।

## यह योजना में क्या जोड़ता है

जिस v7 योजना का अनुबंध `agent_delegation` अनुमति देता है, उसमें `execute` किसी `parallel_safe` कार्य को दूसरे CLI को सौंप सकता है: यह एक समर्पित git worktree बनाता है, वहाँ timeout के साथ `ak run` चलाता है, और परिणाम को योजना की `analysis_results/delegations/` में एकत्र करता है। परिणाम तब तक `asserted` साक्ष्य है जब तक योजना का अपना गेट रनर उसे देख न ले। किसी प्रत्यायोजित एजेंट को रद्द करने से उसका पूरा process tree रुक जाता है।

## Agentkit या Herdr

| स्थिति | उपयोग करें |
|---|---|
| घोषित आउटपुट वाला एक सीमित `parallel_safe` कार्य | Agentkit (headless) |
| कार्य को इंटरैक्शन चाहिए, वह लंबा चलता है, या किसी दूसरी मशीन पर है | [Herdr](/kit/herdr) (पेन में एक पीयर) |

दोनों साथ मिलकर काम करते हैं: herdr-peers किसी पेन में उस environment के साथ पीयर लॉन्च कर सकता है जिसे `ak env <kind> @profile` प्रिंट करता है। एक साथ कई लेन के लिए, [कई एजेंट चलाना](/methodology/06-orchestration) देखें।

## टिप्पणियाँ

वैकल्पिक और कभी आवश्यक नहीं। API कुंजियों के मान कभी प्रिंट, लॉग या किसी config फ़ाइल में नहीं लिखे जाते; प्रलेखित अपवाद Cline है, जो अपनी कुंजी कमांड लाइन पर प्राप्त करता है। OpenCode, Pi, Cline और Grok के लिए परिणाम-निष्कर्षण विक्रेता प्रलेखन से बनाया गया है और अभी तक वास्तविक खातों पर परखा नहीं गया है; अज्ञात आउटपुट कच्चे टेक्स्ट पर लौट आता है।
