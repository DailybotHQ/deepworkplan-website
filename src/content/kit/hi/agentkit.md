# Agentkit addon

हर टर्मिनल कोडिंग एजेंट के पास सत्र जारी रखने के अपने फ़्लैग, दूसरे खाते को अलग रखने का अपना तरीका, अपना headless मोड और अनुमति प्रॉम्प्ट छोड़ने का अपना स्विच होता है। **[coding-agents-kit](https://github.com/DailybotHQ/coding-agents-kit)** इन सभी के ऊपर एक ही कमांड सतह रखता है: `ak <kind> [@profile]`।

यह ऐडऑन इस kit को **DWP v7** (पैक `v7.1.4`) में **headless** प्रत्यायोजन ट्रांसपोर्ट के रूप में एकीकृत करता है। यह वैकल्पिक है: इसके बिना हर कार्य वर्तमान सत्र में ही चलता है, ठीक पहले की तरह। kit स्वयं एक MIT उत्पाद है जो Deep Work Plan के बिना भी काम करता है।

## kit आपको क्या देता है

- **हर CLI के लिए एक व्याकरण।** `ak claude`, `ak codex`, `ak cursor`, `ak opencode`, `ak pi`, `ak cline` और `ak grok`, साथ ही प्रदाता वेरिएंट (GLM, Azure, xAI), एक जैसे सत्र फ़्लैग के साथ: `-c` जारी रखता है, `-r <id>` फिर से शुरू करता है।
- **प्रोफ़ाइल।** `ak claude @work` एक दूसरे खाते को उसकी अपनी home में चलाता है, पहले खाते से अलग।
- **headless रन।** `ak run <kind> -- "<prompt>"` एक प्रॉम्प्ट को गैर-इंटरैक्टिव रूप से चलाता है और एक प्रलेखित exit code लौटाता है, वैकल्पिक रूप से एक JSON ऑब्जेक्ट के रूप में।
- **एक doctor।** `ak doctor --json` बताता है कि कौन-से CLI इंस्टॉल हैं, कौन-सी प्रोफ़ाइलें हैं, और सेट की गई कुंजियों के नाम — उनके मान कभी नहीं।
- **सत्यापित इंस्टॉल।** `ak install <cli>` किसी अनुपस्थित CLI को उसके विक्रेता के आधिकारिक चैनल से एक पिन किए गए संस्करण पर इंस्टॉल करता है, जिसे एक पिन किए गए sha256 या npm रजिस्ट्री की integrity से जाँचा जाता है।
- **परिचित नाम।** दो alias presets, जो तब तक बंद रहते हैं जब तक आप उन्हें चालू न करें: `classic` (`claudex`, `codexx`, `cursorx`, `opencodex`, `pix`, `clinex`, `grokx`) और `providers` (`claude-glm`, `codex-azure`, `codex-xai`, `pi-glm`, …), जिनमें से हर एक एक `ak <kind>` है।

## इंस्टॉल

```bash
git clone --branch v0.3.0 https://github.com/DailybotHQ/coding-agents-kit && ./coding-agents-kit/install.sh
ak doctor
```

आवश्यकताएँ: macOS या Linux पर `bash`, और `python3` 3.9 या नया; और कुछ नहीं। Windows `install.ps1` का उपयोग करता है। `v0.3.0` पिन करें: `v0.2.0` और `v0.2.1` समर्थित नहीं हैं। किसी रिलीज़ को उसके `SHA256SUMS` asset से सत्यापित करें।

| मद | मान |
|---|---|
| उत्पाद | `DailybotHQ/coding-agents-kit`, tag `v0.3.0`, इंटरफ़ेस 1 |
| रजिस्ट्री कुंजी | `.dwp/config.json` में `agentkit` |
| ट्रांसपोर्ट | headless: हर प्रत्यायोजित एजेंट के लिए एक समर्पित git worktree में एक `ak run` |
| प्रदान करता है | `subagents`, `cancel_children`, `model_routing` |
| आवश्यकता | योजना अनुबंध की `agent_delegation` अनुमति |

## डिफ़ॉल्ट रूप से स्वायत्तता, ऐसे opt-out के साथ जो हमेशा प्रभावी रहता है

`v0.2.0` से, `ak <kind>` हर एजेंट को **स्वायत्तता** में लॉन्च करता है: यह CLI का अपना स्वायत्तता फ़्लैग जोड़ता है, जो केवल kit की `providers.toml` में रखा जाता है। स्वायत्तता डिस्पोज़ेबल या sandboxed परिवेशों के लिए है, जैसे एक development container।

**opt-out हमेशा प्रभावी रहता है**: किसी एक कमांड पर `--ask`, या environment में या kit की env फ़ाइल में `AGENTKIT_PERMISSIONS=ask`, फ़्लैग को दबा देता है, तब भी जब वही कमांड `--auto` कहे। opt-out किया गया सत्र यह opt-out उन एजेंटों तक पहुँचाता है जिन्हें वह शुरू करता है। होस्ट पर opt-out सेट करें।

ऐडऑन कोई स्वायत्तता फ़्लैग नहीं लिखता और कभी `--auto` पास नहीं करता। जब कोई योजना opt-out दर्ज करती है, तब यह `--ask` पास करता है। होस्ट पर `agent_delegation` अनुमति देने वाली योजना ऐसे स्वायत्त प्रत्यायोजित एजेंटों को स्वीकार करती है जो अपने worktree तक सीमित हैं, और worktree कोई sandbox नहीं है।

## यह योजना में क्या जोड़ता है

जिस v7 योजना का अनुबंध `agent_delegation` अनुमति देता है, उसमें `execute` किसी `parallel_safe` कार्य को दूसरे CLI को सौंप सकता है: यह एक समर्पित git worktree बनाता है, वहाँ timeout के साथ `ak run` चलाता है, और परिणाम को योजना की `analysis_results/delegations/` में एकत्र करता है। परिणाम तब तक `asserted` साक्ष्य है जब तक योजना का अपना गेट रनर उसे देख न ले। किसी प्रत्यायोजित एजेंट को रद्द करने से उसका पूरा process tree रुक जाता है।

## Agentkit या Herdr

| स्थिति | उपयोग करें |
|---|---|
| घोषित आउटपुट वाला एक सीमित `parallel_safe` कार्य | Agentkit (headless) |
| कार्य को इंटरैक्शन चाहिए, वह लंबा चलता है, या किसी दूसरी मशीन पर है | [Herdr](/kit/herdr) (पेन में एक पीयर) |

दोनों साथ मिलकर काम करते हैं: herdr-peers किसी पेन में उस environment के साथ पीयर लॉन्च कर सकता है जिसे `ak env <kind> @profile` प्रिंट करता है।

## टिप्पणियाँ

वैकल्पिक और कभी आवश्यक नहीं। API कुंजियों के मान कभी प्रिंट, लॉग या किसी config फ़ाइल में नहीं लिखे जाते; प्रलेखित अपवाद Cline है, जो अपनी कुंजी कमांड लाइन पर प्राप्त करता है। OpenCode, Pi, Cline और Grok के लिए परिणाम-निष्कर्षण विक्रेता प्रलेखन से बनाया गया है और अभी तक वास्तविक खातों पर परखा नहीं गया है; अज्ञात आउटपुट कच्चे टेक्स्ट पर लौट आता है।
