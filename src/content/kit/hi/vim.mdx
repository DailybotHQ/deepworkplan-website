# DeepWorkPlan Vim ऐडऑन

**DeepWorkPlan Vim** Deep Work Plan का टर्मिनल एडिटर है: Neovim का एक कॉन्फ़िगरेशन (यह स्वयं एडिटर है, रिपॉज़िटरी फ़ाइल नहीं) जो मेथडोलॉजी की कार्य-सतहों को एक कीस्ट्रोक की दूरी पर रख देता है। जहाँ kit की बाकी प्रविष्टियाँ रिपॉज़िटरी में harness इंस्टॉल करती हैं, यह ऐडऑन इंसान को — और headless रूप से Neovim चलाने वाले किसी भी एजेंट को — ऐसा एडिटर देता है जो DWP को मूल रूप से बोलता है।

इसे **Neovim 0.12 या नया** चाहिए, यह **macOS और Linux** पर चलता है (Windows के लिए दस्तावेज़ित मैनुअल रास्ता है) और **GPL-3.0** लाइसेंस के अंतर्गत है — उपयोग, अध्ययन और संशोधन के लिए स्वतंत्र।

## यह क्या जोड़ता है

| # | सुविधा | क्या करती है | मैपिंग |
|---|---------|--------------|---------|
| F1 | **जनरेट किया गया कमांड इंडेक्स** | पूरा एडिटर, सूचीबद्ध: हर कमांड अपनी मैपिंग और एक-पंक्ति विवरण के साथ; जीवित कॉन्फ़िगरेशन से जनरेट होता है, इसलिए इंडेक्स एडिटर से भटक नहीं सकता। | `SPC h h` |
| F2 | **VS Code शैली के जेस्चर** | सब चुनें, कॉपी और क्लिपबोर्ड-yank उन अक्षर-संयोजनों (chords) पर जो मांसपेशी-स्मृति पहले से जानती है। | `<C-a>`, `y`, `<leader>y` |
| F3 | **Deep Work Plan ब्राउज़र** | रिपॉज़िटरी को चलाने वाला प्लान खोलता है — कार्य, गेट और पूर्णता की स्थिति — एडिटर छोड़े बिना। | `SPC P` |
| F4 | **Markdown व्यूअर** | Markdown को वैसे पढ़ता है जैसे एजेंट पढ़ते हैं: रेंडर किया गया प्रीव्यू, या कॉपी-पेस्ट की शुद्धता के लिए कच्चा स्रोत। | `SPC m p`, `SPC m r` |
| F5 | **एक-पंक्ति इंस्टॉलर** | macOS और Linux के लिए consent-first `install.sh`; दस्तावेज़ित मैनुअल रास्ता Windows को कवर करता है। | `curl -fsSL https://deepworkplan.com/vim/install.sh \| bash` |

## इंस्टॉल

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

<VimInstall lang="hi" />

इंस्टॉलर **consent-first** है: मौजूदा, पराया Neovim कॉन्फ़िगरेशन कभी ओवरराइट नहीं होता। बिना टर्मिनल पाइप किए यह निर्देशों के साथ रुक जाता है, कुछ छेड़े बिना; इंटरैक्टिव रूप से यह मौजूदा कॉन्फ़िगरेशन को अलग करने से पहले पूछता है। प्लगइन पहली लॉन्च पर headless इंस्टॉल होते हैं — बंद करके दोबारा खोलने का नाटक नहीं।

Windows `curl | bash` का लक्ष्य नहीं है। दस्तावेज़ित मैनुअल रास्ता (winget और Git Bash, या WSL) रिपॉज़िटरी README में है।
