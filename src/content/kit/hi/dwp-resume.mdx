# dwp-resume

एक बाधित Deep Work Plan को स्थायी रिकॉर्ड से फिर से शुरू करें।

<CmdResume lang="hi" class="not-prose my-8" />

## यह क्या करता है

`dwp-resume` एक बाधित योजना को केवल वर्कस्पेस आर्टिफ़ैक्ट्स से, दोहरे निष्पादन के बिना, सुरक्षित रूप से आगे बढ़ाता है। यह `journal.ndjson` और `contract.json` से स्थिति का नियतात्मक पुनर्निर्माण करता है, लंबित हैंडऑफ़ पैकेट पढ़ता है, और पहले अपूर्ण task से जारी रखता है।

## उपयोग

```
/dwp-resume [plan]
```

## व्यवहार

1. **रिकॉर्ड पढ़ना:** `.dwp/plans/PLAN_<id>_<slug>/` के अंतर्गत `contract.json` और `journal.ndjson` की जाँच करता है।
2. **स्थिति प्रक्षेपित करना:** केवल-जोड़ने-योग्य जर्नल से `state.json` को नियतात्मक रूप से पुनः उत्पन्न करने के लिए `ledger.py project` चलाता है। असहमति होने पर जर्नल को प्राथमिकता मिलती है।
3. **हैंडऑफ़ ग्रहण:** चल रहे इरादे, असत्यापित गेट और खुले peer अनुरोधों को पुनर्प्राप्त करने के लिए लंबित swarm हैंडऑफ़ पैकेट (`dwp-handoff-v1`) की जाँच करता है।
4. **जोड़ का सत्यापन:** फिर से शुरू करने से पहले git स्थिति जाँचता है और प्रभावित सतहों पर smoke check चलाता है।
5. **जारी रखना:** पहले खुले task को मानक निष्पादन लूप के माध्यम से निष्पादित करता है। पुरानी v5 योजनाएँ बिना ज़बरदस्ती माइग्रेशन के अपने दर्ज `PROGRESS.md` प्रवाह से जारी रहती हैं।
