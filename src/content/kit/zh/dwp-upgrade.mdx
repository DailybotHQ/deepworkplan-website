# dwp-upgrade

在获得显式同意的情况下保持已安装的 Deep Work Plan 技能及声明的标准处于最新状态。

## 功能介绍

 检查上游发布以获取技能包和标准的较新版本。它会报告差异，显示本地适配情况，在执行更改前要求开发者显式批准，并安装固定的稳定版本标签，同时不改动  下的既有计划。

## 使用方式



## 行为流程

1. **检查（只读）** — 从  读取已安装版本并查询上游 git 标签以获取最新的稳定版本。报告当前版本与最新版本。
2. **同意** — 通过 diff 显示任何本地修改或适配；未经开发者显式确认，绝不下发或覆盖文件。
3. **升级** — 将精确的稳定标签安装到 ，在  中补齐配置的插件，并调和 harness。
4. **保留历史** —  下的既有计划、证据和日志属于不可变历史，在升级期间绝不被修改或迁移。
