# dwp-create

从一个高层目标创建一份新的 Deep Work Plan。

<CmdCreate lang="zh" class="not-prose my-8" />

## 它做了什么

`dwp-create` 接收一个高层目标，并把它转化为一份结构化的计划。它会分析目标、在需要时提出澄清性的问题、把工作分解为一系列连续的任务，并写出计划文件。

## 用法

```
/dwp-create <goal>
```

## 模式

`dwp-create` 默认采用**引导**模式：它会收集上下文、执行分析，并直接物化出一份 Lite 计划——一份紧凑且已可执行的提案，而非可丢弃的草稿——**展示给你看，并询问是保留为 Lite、晋升为按任务分文件的 Full 计划、编辑，还是停止**——这样你在决定之前总能先读到真实的计划。这是推荐的默认方式，尤其是在最初的几次。

把 **`trust`**（或 `auto`）作为最后一个词追加进去，即可跳过这次审阅——代理会直接进入一份预先批准、可直接运行的计划（Lite 或 Full，由相同的信号决定）：

```
/dwp-create <goal> trust
```

trust 模式是你信任这套流程之后的进阶用户捷径；引导模式则默认让人参与其中。

## 行为

1. 分析目标与仓库上下文。
2. 若含糊则提出澄清性的问题。
3. 直接在 `.dwp/plans/PLAN_<name>/` 下物化计划——默认是 Lite 计划，较大的工作则是 Full 计划（在引导模式下，审阅它并选择保留为 Lite、晋升为 Full、编辑或停止）。
4. 分解为一系列连续的任务，并写出 README、任务文件与 PROGRESS。
5. 以 Final Review 作结（安全审查、最终状态验证、技能决策核对）。

## 别名

- `dwp:create`
