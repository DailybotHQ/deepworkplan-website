# dwp-resume

从持久记录恢复一份被中断的 Deep Work Plan。

<CmdResume lang="zh" class="not-prose my-8" />

## 它做了什么

`dwp-resume` 仅凭工作区产物安全地继续一份被中断的计划，不会重复执行。它从 `journal.ndjson` 与 `contract.json` 确定性地重建状态，读取待处理的交接包，然后从第一项未完成的任务继续。

## 用法

```
/dwp-resume [plan]
```

## 行为

1. **读取记录：** 检查 `.dwp/plans/PLAN_<id>_<slug>/` 下的 `contract.json` 与 `journal.ndjson`。
2. **投影状态：** 运行 `ledger.py project`，从仅追加的日志确定性地重新生成 `state.json`。出现分歧时以日志为准。
3. **吸收交接：** 检查待处理的 swarm 交接包（`dwp-handoff-v1`），以恢复进行中的意图、未验证的关卡与未结的同伴请求。
4. **校验衔接：** 在恢复之前检查 git 状态，并对涉及的表面运行冒烟检查。
5. **继续：** 通过标准执行循环执行第一项未完成的任务。旧版 v5 计划继续使用其记录的 `PROGRESS.md` 流程，不会被强制迁移。

## 别名

- `dwp:resume`
