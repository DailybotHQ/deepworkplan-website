# dwp-create

高レベルの目標から新しい Deep Work Plan を作成します。

<CmdCreate lang="ja" class="not-prose my-8" />

## 何をするか

`dwp-create` は高レベルの目標を受け取り、それを構造化された計画へと変えます。目標を分析し、必要なら明確化のための質問をし、作業を逐次的なタスクへと分解し、計画ファイルを書きます。

## 使い方

```
/dwp-create <goal>
```

## モード

`dwp-create` は既定で**ガイド付き**モードです。コンテキストを収集し、分析を実行し、Lite 計画を直接マテリアライズします——コンパクトで既に実行可能な提案であり、使い捨てのドラフトではありません——**それをあなたに見せ、Lite のまま維持するか、タスクファイル形式の Full 計画へ昇格させるか、編集するか、中止するかを尋ねます**。これにより、決定する前に必ず実際の計画を読むことになります。これが推奨される既定であり、特に最初の数回はそうです。

確認を飛ばすには、最後の語として **`trust`**（または `auto`）を付け加えます。エージェントはそのレビューを飛ばし、そのまま事前承認済みの実行可能な計画（同じシグナルで選ばれる Lite または Full）へ進みます。

```
/dwp-create <goal> trust
```

trust モードは、フローを信頼できるようになったうえでのパワーユーザー向けの近道です。ガイド付きモードは既定で人をループの中に保ちます。

## 振る舞い

1. 目標とリポジトリのコンテキストを分析する。
2. 曖昧なら明確化のための質問をする。
3. `.dwp/plans/PLAN_<name>/` の下に計画を直接マテリアライズする——既定では Lite 計画、より大きな作業では Full 計画（ガイド付きモードでは、レビューして Lite のまま維持するか、Full へ昇格させるか、編集するか、中止するかを選ぶ）。
4. 逐次的なタスクへと分解し、README、タスクファイル、PROGRESS を書く。
5. Final Review（セキュリティパス、最終状態検証、スキルの突き合わせ）で締めくくる。
