# dwp-upgrade

明示的な同意を得て、インストールされた Deep Work Plan スキルと宣言された標準を最新状態に維持します。

## 機能概要

 は上流リリースを検査して、スキルパックと標準の新しいバージョンを確認します。差分を報告し、ローカルの適応を表示し、変更を加える前に開発者の明示的な承認を要求し、 配下の既存プランを変更することなく固定の安定リリースタグをインストールします。

## 使用法



## 動作フロー

1. **確認（読み取り専用）** —  からインストール済みバージョンを読み取り、上流 git タグに最新の安定リリースを問い合わせます。現在バージョンと最新バージョンを報告します。
2. **同意** — diff を通じてローカルの変更や適応を表示します。開発者の明示的な確認なしにファイルをダウンロードまたは上書きすることはありません。
3. **アップグレード** — 正確な安定タグを  にインストールし、 内の設定済みアドオンを補完し、ハーネスを調整します。
4. **履歴の保護** —  配下の既存プラン、エビデンス、ログは不変の履歴であり、アップグレード中に変更または移行されることはありません。
