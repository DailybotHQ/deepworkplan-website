# dwp-resume

中断された Deep Work Plan を永続的な記録から再開します。

<CmdResume lang="ja" class="not-prose my-8" />

## 何をするか

`dwp-resume` は、ワークスペースの成果物だけを頼りに、中断された計画を重複実行なしで安全に続行します。`journal.ndjson` と `contract.json` から状態を決定論的に再構築し、保留中の引き継ぎパケットを読み、最初の未完了タスクから続行します。

## 使い方

```
/dwp-resume [plan]
```

## 振る舞い

1. **記録の読み取り：** `.dwp/plans/PLAN_<id>_<slug>/` の下の `contract.json` と `journal.ndjson` を調べる。
2. **状態の投影：** `ledger.py project` を実行し、追記専用のジャーナルから `state.json` を決定論的に再生成する。食い違いはジャーナルを優先して解決する。
3. **引き継ぎの取り込み：** 保留中の swarm 引き継ぎパケット（`dwp-handoff-v1`）を確認し、進行中の意図、未検証のゲート、未解決のピアへの依頼を回復する。
4. **継ぎ目の検証：** 再開前に git の状態を確認し、変更対象の箇所でスモークチェックを実行する。
5. **続行：** 最初の未完了タスクを標準の実行ループで実行する。旧来の v5 計画は、強制的な移行なしに記録された `PROGRESS.md` のフローで続行する。

## エイリアス

- `dwp:resume`
