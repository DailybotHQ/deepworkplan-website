# dwp-refine

既存の Deep Work Plan を改良します。

<CmdRefine lang="ja" class="not-prose my-8" />

## 何をするか

`dwp-refine` は既存の計画を修正します。完了済みの作業を保持し、タスク表を更新しながら、タスクの追加、削除、並べ替えができます。

## 使い方

```
/dwp-refine [plan]
```

## 振る舞い

1. 既存の計画を読む。
2. タスクを追加、削除、または並べ替える。
3. 完了済みの作業を保持する。
4. タスク表を更新する。
5. 何が、なぜ変わったかを記録する。

> スキルをアップグレードしても、既存の計画は記録された世代を維持します。移行は自動ではありません。旧形式の3つの最終タスクは、明示的に保持された v5 Final Review 形式へ移行できます。v5 計画を v6 に移行するには、明示的な依頼と事前確認が必要です。

## Lite 計画を Full へ昇格させる

`/dwp-refine promote {plan_name}` は、Lite 計画の正本表現を README 内のインラインなタスク記録からタスクごとのファイルへ切り替え、範囲を変えずに完了済みの作業とタスク ID を保持します。昇格は表現形式のみに関わるものです——execute を呼び出すことは決してありません。Full 計画が自動的に Lite へ降格されることはありません。

## エイリアス

- `dwp:refine`
