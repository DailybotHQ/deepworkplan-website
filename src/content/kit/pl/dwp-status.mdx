# dwp-status

Zgłoś status Deep Work Plan bez jego wykonywania.

<CmdStatus lang="pl" class="not-prose my-8" />

## Co robi

`dwp-status` podsumowuje postęp planu bez wprowadzania zmian. Zgłasza zadania ukończone, w toku i oczekujące.

## Użycie

```
/dwp-status
/dwp-status [plan]
```

## Zachowanie

1. 4 lifecycle dimensions (format, materialization, review, progress); Przeczytanie planu i `PROGRESS.md`.
2. Podsumowanie ukończonych zadań.
3. Podsumowanie zadań w toku.
4. Resource envelope & blockers (C1–C7); Podsumowanie zadań oczekujących.
5. Delegations observation; Zgłoszenie bez modyfikowania czegokolwiek.

## Aliasy

- `dwp:status`
