# dwp-status

Zgłoś status Deep Work Plan bez jego wykonywania.

<CmdStatus lang="pl" class="not-prose my-8" />

## Co robi

`dwp-status` z mocy kontraktu działa wyłącznie w trybie odczytu. Podsumowuje postęp, aktywne blokery, punkty kontrolne i obwiednie zasobów, nie zmieniając żadnego pliku.

## Użycie

```
/dwp-status                      # list and summarize all plans
/dwp-status [plan]               # report details for a specific plan
```

## Zachowanie

1. **Cztery wymiary cyklu życia:** raportuje format (`lite` lub `full`), stan materializacji (`materializing`, `ready` lub `promoting`), zatwierdzenie przeglądu (`pending`, `approved` lub `pre_approved`) oraz postęp wykonania (`pending`, `in_progress`, `blocked` lub `completed`).
2. **Przegląd całego repozytorium:** wywołane bez argumentów wyświetla wszystkie plany w `.dwp/plans/` wraz z procentem ukończenia, lokalizatorami aktywnych zadań i podsumowaniami blokerów.
3. **Obwiednia zasobów:** pokazuje zużycie względem pułapów w śledzonych wymiarach (`wall_clock`, ponowienia, przekazania, wydatki, tokeny) i wskazuje, czy limity są aktywnie egzekwowane, czy mają charakter doradczy.
4. **Diagnoza blokerów:** przedstawia szczegóły aktywnych blokerów z `state.json.blocked`, sklasyfikowane według standardowej taksonomii eskalacji (klasy C1–C7).
5. **Obserwacja delegacji:** podsumowuje otwarte i ukończone delegacje do subagentów oraz zarejestrowane wymiany z peerami.
