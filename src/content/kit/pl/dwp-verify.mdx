# dwp-verify

Obiektywnie sprawdź zgodność repozytorium i planu — tylko do odczytu.

<CmdVerify lang="pl" class="not-prose my-8" />

## Co robi

`dwp-verify` sprawdza mechanicznie, czy repozytorium jest AI-first (zgodne z DeepWorkPlan) i czy jego plany są poprawnie sformułowane, a następnie zgłasza wynik pass/fail. Niczego nie zmienia.

## Użycie

```
/dwp-verify            # verify the repository
/dwp-verify plan auth  # also verify a specific plan
/dwp-verify all        # repository + every plan
```

## Zachowanie

1. Sprawdzenie repozytorium: `AGENTS.md` z rzeczywistymi, wykonywalnymi komendami; rozwiązanie `CLAUDE.md`; kategorie `docs/`; katalog `.agents/` zgodny z dyskiem; cienkie delegatory `dwp-*`; pomijane przez git `.dwp/` i `tmp/`; rozwiązywalny skill.
2. Sprawdzenie planu (na żądanie): każde zadanie ma kryteria akceptacji i bramkę walidacji, postęp jest zapisywany, obecny jest zapisany Final Review (wraz z jego przeglądem bezpieczeństwa), a zadania na nowo odnoszą się do celu.
3. Zgłoszenie **CONFORMANT** lub **NOT CONFORMANT** wraz z wymienieniem każdego niepowodzenia.
4. Zaproponowanie ujęcia braków w postaci Deep Work Plan; nigdy nie naprawia po cichu.

**Walidacja planów według generacji.** Kontroler pochodzenia repozytorium akceptuje aktualny standard DWP 7.0.0, ale plany sprawdza się zależnie od generacji. Plan v6 lub v7 jest rozpoznawany po wskaźniku contract w swoim manifeście, pliku `contract.json` lub łańcuchu rewizji `contracts/` i oceniany w trybie tylko do odczytu względem własnych zapisów przez `conformance.sh --plan`: każda rewizja contract przechodzi walidację, manifest odpowiada generacji contract, journal jest nienaruszony i poprawny, zatwierdzenie odwołuje się do obowiązującego contract, a `state.json` zgadza się z projekcją journal (nieaktualny snapshot jest jedynie ostrzeżeniem i jest generowany ponownie, nigdy nie edytuje się go ręcznie). Kontrole cyklu życia v5 dotyczą wyłącznie planów v5 i starszych, a finalizacja v5 odrzuca plan v6 lub v7. Generacje współistnieją i żadna nie jest migrowana podczas weryfikacji.
