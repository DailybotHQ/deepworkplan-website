# dwp-resume

Retoma um Deep Work Plan interrompido.

<CmdResume lang="pt" class="not-prose my-8" />


## O que faz

`dwp-resume` continua com segurança um plano interrompido apenas a partir de artefatos do workspace, sem execução duplicada. Reconstrói deterministicamente o estado a partir de `journal.ndjson` e `contract.json`, lê pacotes de transição pendentes e continua da primeira tarefa incompleta.

## Uso

```
/dwp-resume [plan]
```

## Comportamento

1. **Leitura de registros:** inspeciona `contract.json` e `journal.ndjson` sob `.dwp/plans/PLAN_<id>_<slug>/`.
2. **Projeção de estado:** executa `ledger.py project` para regenerar deterministicamente `state.json` a partir do diário somente de adição. Divergências resolvem a favor do diário.
3. **Ingestão de transição:** verifica pacotes de transição de swarm pendentes (`dwp-handoff-v1`) para recuperar intenção em voo, gates não verificados e solicitações abertas de pares.
4. **Verificação de costura:** confere status do git e executa smoke tests nas superfícies tocadas antes de retomar.
5. **Continuação:** executa a primeira tarefa aberta pelo loop de execução padrão. Planos v5 legados continuam usando o fluxo registrado em `PROGRESS.md` sem migração forçada.
