# dwp-status

Riferisce sullo stato di un Deep Work Plan senza eseguirlo.

<CmdStatus lang="it" class="not-prose my-8" />

## Cosa fa

`dwp-status` riassume i progressi del piano senza apportare modifiche. Riferisce sulle attività completate, in corso e in sospeso.

## Uso

```
/dwp-status
/dwp-status [plan]
```

## Comportamento

1. 4 lifecycle dimensions (format, materialization, review, progress); Legge il piano e `PROGRESS.md`.
2. Riassume le attività completate.
3. Riassume le attività in corso.
4. Resource envelope & blockers (C1–C7); Riassume le attività in sospeso.
5. Delegations observation; Riferisce senza modificare nulla.

## Alias

- `dwp:status`
