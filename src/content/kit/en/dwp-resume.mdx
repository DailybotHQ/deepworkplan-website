# dwp-resume

Resume an interrupted Deep Work Plan from durable records.

<CmdResume lang="en" class="not-prose my-8" />

## What it does

`dwp-resume` safely continues an interrupted plan from workspace artifacts alone without duplicate execution. It deterministically reconstructs state from `journal.ndjson` and `contract.json`, reads pending handoff packets, and continues from the first incomplete task.

## Usage

```
/dwp-resume [plan]
```

## Behavior

1. **Read records:** inspects `contract.json` and `journal.ndjson` under `.dwp/plans/PLAN_<id>_<slug>/`.
2. **Project state:** runs `ledger.py project` to deterministically regenerate `state.json` from the append-only journal. Disagreements resolve in favor of the journal.
3. **Handoff ingestion:** checks for pending swarm handoff packets (`dwp-handoff-v1`) to recover in-flight intent, unverified gates, and open peer asks.
4. **Verify seam:** checks git status and runs smoke checks on touched surfaces before resuming.
5. **Continue:** executes the first open task through the standard execution loop. Legacy v5 plans continue using their recorded `PROGRESS.md` flow without forced migration.
