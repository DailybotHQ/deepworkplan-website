# dwp-resume

Відновлює перерваний Deep Work Plan із довготривалих записів.

<CmdResume lang="uk" class="not-prose my-8" />

## Що це робить

`dwp-resume` безпечно продовжує перерваний план лише за артефактами робочого простору, без повторного виконання. Він детерміновано відновлює стан із `journal.ndjson` і `contract.json`, читає очікувані пакети передачі та продовжує з першої незавершеної задачі.

## Використання

```
/dwp-resume [plan]
```

## Поведінка

1. **Читання записів:** вивчає `contract.json` і `journal.ndjson` у `.dwp/plans/PLAN_<id>_<slug>/`.
2. **Проєкція стану:** запускає `ledger.py project`, щоб детерміновано заново побудувати `state.json` із журналу, що допускає лише додавання. Розбіжності розв'язуються на користь журналу.
3. **Приймання передачі:** перевіряє наявність очікуваних пакетів передачі рою (`dwp-handoff-v1`), щоб відновити наміри в процесі виконання, неперевірені шлюзи та відкриті запити пірів.
4. **Перевірка стику:** перевіряє стан git і перед відновленням проганяє smoke-перевірки зачеплених поверхонь.
5. **Продовження:** виконує першу відкриту задачу через стандартний цикл виконання. Застарілі плани v5 продовжують працювати за записаним потоком `PROGRESS.md` без примусової міграції.

## Аліаси

- `dwp:resume`
