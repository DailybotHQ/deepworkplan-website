# dwp-execute

Виконує наявний Deep Work Plan задача за задачею.

<CmdExecute lang="uk" class="not-prose my-8" />

## Що це робить

`dwp-execute` виконує наявний план задача за задачею через детермінований шар записів. Він визначає цільовий план, оцінює залежності, виконує кожну задачу в оголошеному порядку, проганяє шлюзи валідації та фіксує незмінний прогрес.

## Використання

```
/dwp-execute                     # execute latest plan
/dwp-execute [plan]              # by exact folder, id, or slug
/dwp-execute [plan] trust        # unattended execution without per-task prompts
```

## Режими

- **Керований (за замовчуванням):** запитує підтвердження між задачами, даючи змогу переглядати докази й рішення на кожній межі задачі.
- **Trust (`auto`):** доданий `trust` послідовно виконує допустимі задачі до завершення без пауз на рутинні підтвердження й зупиняється лише за справжнього блокування (класи ескалації C1–C7).

## Поведінка

1. **Визначення плану:** знаходить план за точною назвою папки, числовим ID, унікальним slug або `latest` (план із найбільшим числовим ID).
2. **Цикл реєстру:** запускає `ledger.py ready` для оцінки DAG залежностей та інваріантів, `ledger.py start` для перевірки передумов і `ledger.py gate` для виконання команд валідації та випуску доказів `observed`.
3. **Захищене завершення:** `ledger.py complete` застосовує контроль проти прогонів без жодного тесту, свіжу оцінку інваріантів і локальні для задачі рішення щодо скілів та документації.
4. **Делегування в межах плану:** задачі, позначені `parallel_safe` у контрактах v7, можуть делегуватися субагентам через headless-транспорт (`ak run` у worktree) або інтерактивний транспорт (панель `herdr`). Результати лишаються `asserted`, доки їх не спостереже виконавець шлюзів плану.
5. **Перевірки місткості:** на межах задач перед диспетчеризацією оцінює залишковий запас облікового запису.
6. **Final Review:** завершується обов'язковою заключною задачею з п'яти частин (перевірка безпеки з обов'язковим локальним рев'ю, валідація фінального стану, звірка скілів, звірка документації, завершення).

## Аліаси

- `dwp:execute`
