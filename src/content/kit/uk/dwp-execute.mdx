# dwp-execute

Виконує наявний Deep Work Plan.

<CmdExecute lang="uk" class="not-prose my-8" />

## Що це робить

`dwp-execute` виконує наявний план задача за задачею. Він читає весь план, виконує кожну задачу по черзі, оновлює `PROGRESS.md` і фіксує статус завершення кожної задачі.

## Використання

```
/dwp-execute
/dwp-execute [plan]
/dwp-execute [plan] trust
```

## Поведінка

1. Прочитати весь план перед початком.
2. `ledger.py ready` & `ledger.py start` -> Виконувати задачі по черзі.
3. `ledger.py gate` -> `observed` evidence; Оновлювати `PROGRESS.md` після кожної задачі.
4. `parallel_safe` delegation; Точно фіксувати статус задачі.
5. `ledger.py complete` & Final Review; Зупинятися й запитувати в разі блокування.

## Аліаси

- `dwp:execute`
