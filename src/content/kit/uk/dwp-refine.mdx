# dwp-refine

Допрацьовує наявний Deep Work Plan.

<CmdRefine lang="uk" class="not-prose my-8" />

## Що це робить

`dwp-refine` змінює наявний план. Він може додавати, вилучати чи змінювати порядок задач, зберігаючи виконану роботу й оновлюючи таблицю задач.

## Використання

```
/dwp-refine [plan]
/dwp-refine promote [plan]
```

## Поведінка

1. Прочитати наявний план.
2. `ledger.py amend` (v7 contracts/); Додати, вилучити чи змінити порядок задач.
3. Зберегти виконану роботу.
4. Оновити таблицю задач.
4. Closed adaptations (split, reorder, insert, change_strategy, retry).
5. Зафіксувати, що змінилося й чому.

> Після оновлення скіла наявні плани зберігають зафіксоване покоління. Міграція ніколи не відбувається автоматично: застаріле завершення з трьох завдань можна явно перенести до збереженої форми Final Review v5; план v5 переходить на v6 лише через явну міграцію з попереднім переглядом. План v6 зберігає своє покоління й виконується без змін; нові плани використовують поточне покоління v7, а план v6 ніколи не переводиться на v7 неявно.

## Підвищення Lite-плану до Full

`/dwp-refine promote {plan_name}` перемикає авторитетне представлення Lite-плану з вбудованих у README записів задач на файли для кожної задачі, зберігаючи виконану роботу й ідентифікатори задач без зміни обсягу. Підвищення стосується лише представлення — воно ніколи не викликає execute. Full-плани автоматично не понижуються назад до Lite.

## Аліаси

- `dwp:refine`
