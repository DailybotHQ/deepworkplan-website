# Аддон DeepWorkPlan Vim

**DeepWorkPlan Vim** — термінальний редактор Deep Work Plan: конфігурація Neovim (це сам редактор, а не файл репозиторію), яка тримає робочі поверхні методології на відстані одного натискання клавіші. Доки інші записи набору встановлюють harness у репозиторій, цей аддон оснащує людину — і будь-якого агента, що керує Neovim у headless-режимі, — редактором, який говорить DWP від природи.

Він вимагає **Neovim 0.12 або новішої**, працює на **macOS і Linux** (Windows підтримується через задокументований ручний шлях) і має ліцензію **GPL-3.0** — вільно використовувати, вивчати й змінювати.

## Що він додає

| # | Можливість | Що робить | Привʼязка |
|---|---------|--------------|---------|
| F1 | **Генерований індекс команд** | Увесь редактор списком: кожна команда зі своєю привʼязкою й описом в один рядок; генерується з живої конфігурації, тож індекс не розбігається з редактором. | `SPC h h` |
| F2 | **Жести в дусі VS Code** | Виділити все, копіювати та yank у буфер обміну на акордах, які мʼязова памʼять уже знає. | `<C-a>`, `y`, `<leader>y` |
| F3 | **Оглядач Deep Work Plan** | Відкриває план, що веде репозиторій, — завдання, ворота й стан завершення — не виходячи з редактора. | `SPC P` |
| F4 | **Переглядач Markdown** | Читає Markdown так, як читають агенти: відтворений передпоказ або сире джерело для точності копіювання. | `SPC m p`, `SPC m r` |
| F5 | **Інсталятор одним рядком** | Згода передусім: `install.sh` для macOS і Linux; задокументований ручний шлях покриває Windows. | `curl -fsSL https://deepworkplan.com/vim/install.sh \| bash` |

## Встановлення

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

Інсталятор **згоди передусім**: чужий наявний конфіг Neovim ніколи не перезаписується. Запущений через канал без терміналу, він переривається з інструкціями, нічого не торкаючи; в інтерактивному режимі питає, перш ніж відсунути наявний конфіг убік. Плагіни встановлюються headless під час першого запуску — без танців із виходом і повторним відкриттям.

Windows не є ціллю `curl | bash`. Задокументований ручний шлях (winget плюс Git Bash або WSL) живе у README репозиторію.

## Коли вдаватися до нього

| Сигнал | Дія |
|--------|--------|
| Розробник живе в терміналі та веде репозиторій за планом | **Запропонуйте** аддон |
| Довгогоризонтне виконання DWP, де оглядач планів (`SPC P`) тримає стан на видноті | **Порадьте** |
| Редактор розробника вже налаштований і не підлягає торгу | **Пропустіть** — аддон опційний за задумом |
| Команда лише на Windows без WSL | **Пропустіть** або вкажіть задокументований ручний шлях |
