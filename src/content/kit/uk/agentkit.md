# Аддон Agentkit

Кожен термінальний агент для програмування має власні прапорці для продовження сесії, власний спосіб відокремити другий обліковий запис, власний headless-режим і власний перемикач для пропуску запитів дозволів. **[coding-agents-kit](https://github.com/DailybotHQ/coding-agents-kit)** накладає на всіх них одну командну поверхню: `ak <kind> [@profile]`.

Цей аддон інтегрує kit у **DWP v7** (пакет `v7.1.4`) як **headless**-транспорт делегування. Він опційний: без нього кожне завдання виконується в поточній сесії, як і раніше. Сам kit — це продукт за ліцензією MIT, який працює без Deep Work Plan.

## Що дає kit

- **Одна граматика для кожного CLI.** `ak claude`, `ak codex`, `ak cursor`, `ak opencode`, `ak pi`, `ak cline` і `ak grok`, а також варіанти провайдерів (GLM, Azure, xAI), з тими самими прапорцями сесії: `-c` продовжує, `-r <id>` відновлює.
- **Профілі.** `ak claude @work` запускає другий обліковий запис у власному домашньому каталозі, відокремленому від першого.
- **Headless-запуски.** `ak run <kind> -- "<prompt>"` виконує один промпт неінтерактивно й повертає задокументований код виходу, за бажанням як один JSON-об’єкт.
- **Doctor.** `ak doctor --json` повідомляє, які CLI встановлено, профілі та назви заданих ключів — ніколи їхні значення.
- **Перевірене встановлення.** `ak install <cli>` встановлює відсутній CLI з офіційного каналу його постачальника в закріпленій версії, звіряючи її із закріпленим sha256 або з integrity з реєстру npm.
- **Звичні назви.** Два пресети псевдонімів, вимкнені, доки ви їх не ввімкнете: `classic` (`claudex`, `codexx`, `cursorx`, `opencodex`, `pix`, `clinex`, `grokx`) і `providers` (`claude-glm`, `codex-azure`, `codex-xai`, `pi-glm`, …), кожен із яких — це `ak <kind>`.

## Встановлення

```bash
git clone --branch v0.3.0 https://github.com/DailybotHQ/coding-agents-kit && ./coding-agents-kit/install.sh
ak doctor
```

Вимоги: `bash` на macOS або Linux і `python3` 3.9 або новіший; більше нічого. Windows використовує `install.ps1`. Закріпіть `v0.3.0`: `v0.2.0` і `v0.2.1` не підтримуються. Перевірте реліз за його ресурсом `SHA256SUMS`.

| Елемент | Значення |
|---|---|
| Продукт | `DailybotHQ/coding-agents-kit`, тег `v0.3.0`, інтерфейс 1 |
| Ключ реєстру | `agentkit` у `.dwp/config.json` |
| Транспорт | headless: один `ak run` на делегата в окремому git worktree |
| Надає | `subagents`, `cancel_children`, `model_routing` |
| Потребує | дозволу `agent_delegation` у контракті плану |

## Автономія за замовчуванням із відмовою, яка завжди перемагає

Починаючи з `v0.2.0`, `ak <kind>` запускає кожного агента в **автономії**: він додає власний прапорець автономії CLI, який зберігається лише в `providers.toml` kit. Автономія призначена для одноразових або ізольованих середовищ, як-от контейнер для розробки.

**Відмова завжди перемагає**: `--ask` для однієї команди або `AGENTKIT_PERMISSIONS=ask` у середовищі чи в env-файлі kit пригнічує прапорець, навіть коли та сама команда вказує `--auto`. Сесія з відмовою передає відмову агентам, яких вона запускає. На хості встановіть відмову.

Аддон не прописує жодного прапорця автономії й ніколи не передає `--auto`. Він передає `--ask`, коли план фіксує відмову. План, який надає `agent_delegation` на хості, приймає автономних делегатів, обмежених власним worktree, а worktree не є пісочницею.

## Що він додає до плану

У плані v7, контракт якого надає `agent_delegation`, `execute` може передати завдання `parallel_safe` іншому CLI: він створює окремий git worktree, запускає там `ak run` з тайм-аутом і збирає результат у `analysis_results/delegations/` плану. Результат є доказом `asserted`, доки власний gate runner плану його не зафіксує. Скасування делегата зупиняє все його дерево процесів.

## Agentkit чи Herdr

| Ситуація | Використовуйте |
|---|---|
| Обмежене завдання `parallel_safe` із задекларованим результатом | Agentkit (headless) |
| Завдання потребує взаємодії, виконується довго або розташоване на іншій машині | [Herdr](/kit/herdr) (peer-агент у панелі) |

Обидва поєднуються: herdr-peers може запустити peer-агента в панелі із середовищем, яке виводить `ak env <kind> @profile`.

## Примітки

Опційний і ніколи не обов’язковий. Значення API-ключів ніколи не виводяться, не журналюються й не записуються у файл конфігурації; задокументованим винятком є Cline, який отримує свій ключ у командному рядку. Видобування результатів для OpenCode, Pi, Cline і Grok побудовано на документації постачальників і ще не перевірялося на реальних облікових записах; нерозпізнаний вивід повертається як сирий текст.
