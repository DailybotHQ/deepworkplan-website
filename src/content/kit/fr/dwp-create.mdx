# dwp-create

Créer un nouveau Deep Work Plan à partir d’un objectif de haut niveau.

<CmdCreate lang="fr" class="not-prose my-8" />

## Ce qu’il fait

`dwp-create` prend un objectif de haut niveau et le transforme en un plan structuré. Il analyse l’objectif, pose des questions de clarification si nécessaire, décompose le travail en tâches séquentielles et écrit les fichiers du plan.

## Utilisation

```
/dwp-create <goal>
```

## Modes

`dwp-create` fonctionne par défaut en mode **guidé** : il rassemble le contexte, exécute l’analyse, et matérialise directement un plan Lite — une proposition compacte déjà exécutable, pas une ébauche jetable — **vous la présente et vous demande si vous souhaitez la conserver telle quelle (Lite), la promouvoir vers un plan Full à fichiers de tâche, la modifier, ou arrêter** — afin que vous lisiez toujours le plan réel avant de décider. C’est la valeur par défaut recommandée, surtout les premières fois.

Ajoutez **`trust`** (ou `auto`) comme dernier mot pour sauter cette relecture — l’agent passe directement à un plan pré-approuvé et prêt à l’exécution (Lite ou Full, choisi selon les mêmes signaux) :

```
/dwp-create <goal> trust
```

Le mode trust est le raccourci pour utilisateurs avertis une fois que vous avez confiance dans le flux ; le mode guidé garde par défaut un humain dans la boucle.

## Comportement

1. Analyser l’objectif et le contexte du dépôt.
2. Poser des questions de clarification en cas d’ambiguïté.
3. Matérialiser le plan directement sous `.dwp/plans/PLAN_<name>/` — un plan Lite par défaut, ou Full pour les travaux plus importants (en mode guidé, le relire et choisir de le conserver en Lite, de le promouvoir vers Full, de le modifier, ou d’arrêter).
4. Décomposer en tâches séquentielles et écrire le README, les fichiers de tâche et PROGRESS.
5. Terminer par le Final Review (passe de sécurité, validation de l’état final, réconciliation des skills).
