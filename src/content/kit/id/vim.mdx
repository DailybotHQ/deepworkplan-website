# DeepWorkPlan Vim

**DeepWorkPlan Vim** adalah editor terminal untuk Deep Work Plan: konfigurasi Neovim untuk manusia, dan untuk agen pemrograman, yang bekerja di terminal. Rencana Anda, dokumentasi Anda, dan indeks semua perintah hanya sejauh satu tombol.

Ini adalah produk terpisah dan opsional. Ia tidak memasang atau mensyaratkan skill Deep Work Plan, dan bukan bagian dari onboarding DWP v6. Anda menambahkannya ke sebuah mesin secara mandiri, dan ia berfungsi sebagai editor ada atau tidaknya rencana.

## Mengapa editor terminal untuk Deep Work Plan

Deep Work Plan adalah folder Markdown di bawah `.dwp/plans/`: sebuah tujuan, tugas atomik, gerbang verifikasi, dan log yang terus berjalan. Manusia meninjaunya, agen menjalankannya, dan keduanya sering melakukannya dari terminal. Editor yang dibuat untuk pekerjaan itu menjaga tiga hal tetap dekat: rencana itu sendiri, dokumentasi di sekitarnya, dan tombol yang memindahkan Anda di antara keduanya.

DeepWorkPlan Vim adalah editor itu. Ia adalah konfigurasi Neovim pilihan — server bahasa, pelengkapan otomatis, linting, pemformatan, pencarian kabur, pohon berkas, dan tema warna pilihan, dimuat secara malas — ditambah beberapa permukaan yang menjadikannya editor untuk Deep Work Plan.

## Tur: indeks perintah yang tidak bisa ketinggalan zaman

Tekan `SPC h h` (Spasi adalah tombol leader), atau jalankan `:DwpCommands`, dan editor mencantumkan setiap pemetaan yang dimilikinya dengan deskripsi satu baris. Daftar ini dihasilkan dari pemetaan tombol yang aktif, sehingga pemetaan yang didefinisikan di mana pun muncul di indeks tanpa perlu didaftarkan, dan indeks tidak bisa ketinggalan zaman.

Itulah seluruh tur: jalankan `nvim`, lalu tekan Spasi, `h`, `h`.

## Yang Anda dapatkan

Lima fitur, masing-masing hanya sejauh satu tombol.

| Fitur | Tombol | Fungsinya |
|---|---|---|
| Indeks perintah yang dihasilkan | `SPC h h` | Setiap pemetaan dalam konfigurasi, dihasilkan dari pemetaan tombol yang aktif. |
| Gestur ala VS Code | `<C-a>`, `SPC y` | Pilih seluruh berkas dengan satu tombol, lalu salin ke papan klip sistem. `y` biasa juga menyalin ke sana, karena papan klipnya berlaku di seluruh sistem. |
| Penjelajah rencana Deep Work Plan | `SPC P` | Bilah samping untuk rencana di repositori Anda, dikelompokkan menurut status dengan bilah progres, dan pembaca untuk satu rencana. |
| Penampil Markdown | `SPC m p`, `SPC m r` | Pratinjau Markdown di peramban, atau render di buffer. |
| Pemasang satu baris | — | Pemasang mandiri untuk macOS, Linux, dan WSL, dengan jalur manual yang terdokumentasi untuk Windows. |

## Rencana tanpa meninggalkan editor

`SPC P`, `:DwpPlans`, atau satu klik pada segmen baris status membuka bilah samping rencana. Ia mencakup setiap folder `.dwp/plans/` di direktori saat ini dan direktori konfigurasi Neovim Anda, dan mengelompokkan rencana mulai dari yang paling butuh perhatian. Di editor, labelnya adalah `Working`, `Needs attention`, `Ready`, `Not started`, dan `Done`. Setiap rencana menampilkan bilah progres.

Tekan Enter pada sebuah rencana untuk membuka pembaca: tujuan dalam satu kalimat, status dan progres, daftar tugas dengan tugas saat ini ditandai, dan lompatan berbahasa sederhana ke berkas milik rencana itu sendiri. Baris status menampilkan rencana aktif secara langsung, dan layar awal mencantumkan tiga teratas. Permukaan-permukaan ini menjelaskan rencana; mereka tidak pernah menulis ke `.dwp/`.

Untuk membaca berkas Markdown sebuah rencana di tempat, `SPC m p` mempratinjau buffer saat ini di peramban dan `SPC m r` merendernya di dalam buffer. Keduanya hanya berfungsi di buffer Markdown.

## Instalasi

Seluruh instalasi hanya satu baris. Menjalankannya memasang apa yang saat ini disediakan repositori di `main`.

<VimInstall lang="id">

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

</VimInstall>

Secara berurutan, pemasang:

1. Memeriksa OS dan manajer paket Anda, lalu memasang git, curl, dan interpreter Lua jika ada yang belum ada.
2. Bertanya sebelum menyentuh konfigurasi Neovim yang sudah ada. Jika dijalankan lewat pipa tanpa terminal, ia berhenti dan tidak mengubah apa pun.
3. Meng-clone repositori ke `~/.config/nvim`, atau memperbaruinya jika sudah ada di sana.
4. Menjalankan `lua install.lua` milik repositori itu sendiri.
5. Memasang plugin secara headless, sehingga tidak ada langkah keluar lalu membuka ulang.

Untuk membaca skrip lebih dulu, unduh dengan `curl -fsSL https://deepworkplan.com/vim/install.sh -o install.sh`, bandingkan SHA-256-nya dengan nilai yang ditampilkan di atas, baca, lalu jalankan `bash install.sh`.

## Persyaratan dan platform

- Neovim 0.12 atau lebih baru. Pasang Neovim lebih dulu; pemasang tidak memasangnya.
- Lua: `lua`, `lua5.4`, atau `luajit`. Pemasang menambahkannya jika belum ada.
- macOS, Linux, dan WSL menjalankan perintah satu baris. Windows memiliki jalur manual yang terdokumentasi di README repositori: pasang Neovim dengan winget, clone repositori ke `%LOCALAPPDATA%\nvim`, dan jalankan `lua install.lua` dari Git Bash.
- Berlisensi GPL-3.0: bebas digunakan, dipelajari, dan dimodifikasi.

## Memperbarui, mengunci versi, dan mencopot

Jalankan pemasang lagi untuk memperbarui. Pemasang bersifat idempoten: checkout DeepWorkPlan Vim yang sudah ada diperbarui dengan fast-forward, dan perubahan lokal tidak pernah di-reset.

Untuk memasang cabang, tag, atau commit tertentu, setel `DWP_VIM_REF`. Tag lama mungkin tidak memuat semua fitur yang dijelaskan di halaman ini.

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | DWP_VIM_REF=<branch-tag-or-commit> bash
```

Untuk mencopot, jalankan `lua delete.lua` dari direktori konfigurasi. Perintah ini menghapus konfigurasi, plugin, data Mason, cache dan status, serta salinan font yang dibuat pemasang, dan membiarkan biner Neovim serta paket sistem Anda.

```bash
cd ~/.config/nvim && lua delete.lua
```

## Pertanyaan

### Apakah ini akan menimpa konfigurasi Neovim saya?

Tidak, bukan tanpa persetujuan Anda. Saat menemukan konfigurasi yang bukan DeepWorkPlan Vim, eksekusi interaktif bertanya dulu sebelum memindahkannya ke `~/.config/previous-deepworkplan-vim`. Tanpa terminal, atau jika jalur cadangan itu sudah ada, ia berhenti dan tidak mengubah apa pun.

### Apakah berfungsi di Windows?

Perintah satu baris tidak berlaku di Windows. Gunakan jalur manual di README repositori, atau jalankan perintah satu baris itu di dalam WSL.

### Apakah saya butuh Deep Work Plan untuk menggunakannya?

Tidak. Ia adalah editor lebih dulu. Ia tidak memasang atau mensyaratkan skill Deep Work Plan; penjelajah rencana hanya tidak punya apa pun untuk dicantumkan sampai folder `.dwp/plans/` ada.

### Bagaimana agen pemrograman menggunakannya?

Ia dibuat untuk manusia dan untuk agen pemrograman yang hidup di terminal. Pemetaan tombolnya dikunci oleh pengujian kontrak, sehingga ingatan otot, dan ekspektasi agen, bertahan melewati pembaruan.

### Versi mana yang saya dapatkan?

Pemasang memasang `main` kecuali Anda menyetel `DWP_VIM_REF`. Halaman ini menjelaskan apa yang dipasangnya; ia tidak mengaitkan fitur mana pun dengan nomor versi.

### Di bawah lisensi apa dan dari mana asalnya?

GPL-3.0. Ia diturunkan dari mu-vim karya Andrés M Prieto, dan kreditnya tetap ada di repositori.
