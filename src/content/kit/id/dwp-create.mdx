# dwp-create

Buat Deep Work Plan baru dari tujuan tingkat tinggi.

<CmdCreate lang="id" class="not-prose my-8" />

## Fungsinya

`dwp-create` mengambil tujuan tingkat tinggi dan mengubahnya menjadi rencana terstruktur. Ia menganalisis tujuan, mengajukan pertanyaan klarifikasi bila perlu, menguraikan pekerjaan menjadi tugas-tugas sekuensial, dan menulis file rencana.

## Penggunaan

```
/dwp-create <goal>
```

## Mode

`dwp-create` secara default berjalan dalam mode **guided**: ia mengumpulkan konteks, menjalankan analisis, dan langsung melakukan materialisasi sebuah rencana Lite — proposal ringkas yang sudah dapat dieksekusi, bukan draf yang akan dibuang — **menunjukkannya kepada Anda, dan menanyakan apakah ingin mempertahankannya sebagai Lite, mempromosikannya menjadi rencana Full berbasis berkas tugas, mengeditnya, atau berhenti** — sehingga Anda selalu membaca rencana yang sebenarnya sebelum memutuskan. Ini adalah default yang direkomendasikan, terutama pada beberapa kali pertama.

Tambahkan **`trust`** (atau `auto`) sebagai kata terakhir untuk melewati tinjauan ini — agent langsung menuju rencana yang telah disetujui sebelumnya dan siap dijalankan (Lite atau Full, dipilih berdasarkan sinyal yang sama):

```
/dwp-create <goal> trust
```

Mode trust adalah pintasan bagi power user setelah Anda memercayai alurnya; mode guided menjaga manusia tetap terlibat secara default.

## Perilaku

1. Analisis tujuan dan konteks repositori.
2. Ajukan pertanyaan klarifikasi bila ambigu.
3. Lakukan materialisasi rencana langsung di bawah `.dwp/plans/PLAN_<name>/` — rencana Lite secara default, atau Full untuk pekerjaan yang lebih besar (dalam mode guided, tinjau dan pilih mempertahankan sebagai Lite, mempromosikan ke Full, mengedit, atau berhenti).
4. Uraikan menjadi tugas-tugas sekuensial dan tulis README, file tugas, serta PROGRESS.
5. Akhiri dengan Final Review (pemeriksaan keamanan, validasi status akhir, rekonsiliasi skills).
