# dwp-execute

Eksekusi Deep Work Plan yang sudah ada.

<CmdExecute lang="id" class="not-prose my-8" />

## Fungsinya

`dwp-execute` menjalankan rencana yang sudah ada, tugas demi tugas. Ia membaca seluruh rencana, mengeksekusi tiap tugas secara berurutan, memperbarui `PROGRESS.md`, dan menandai status penyelesaian setiap tugas.

## Penggunaan

```
/dwp-execute
/dwp-execute [plan]
/dwp-execute [plan] trust
```

## Perilaku

1. Baca seluruh rencana sebelum memulai.
2. `ledger.py ready` & `ledger.py start` -> Eksekusi tugas secara berurutan.
3. `ledger.py gate` -> `observed` evidence; Perbarui `PROGRESS.md` setelah tiap tugas.
4. `parallel_safe` delegation; Tandai status tugas secara akurat.
5. `ledger.py complete` & Final Review; Berhenti dan bertanya saat terhambat.

## Alias

- `dwp:execute`
