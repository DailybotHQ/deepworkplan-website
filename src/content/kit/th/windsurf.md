# อะแดปเตอร์ Windsurf

Windsurf รองรับ DWP ผ่านระบบกฎและขั้นตอนคำสั่งแบบ markdown

## ระดับการรองรับ

**สมบูรณ์** (ผ่านการทดสอบการติดตั้ง) — Windsurf อ่านกฎของโครงการและรันทุกคำสั่ง dwp-* จากไฟล์ขั้นตอนการทำงาน เส้นทางได้รับการยืนยันโดยชุดการทดสอบอัตโนมัติ

## การติดตั้ง

คำสั่ง DWP อยู่ในรูปขั้นตอนแบบ markdown ที่ agent อ่านผ่านระบบกฎของ Windsurf

## การเรียกใช้

ใช้คำนำหน้า `#`

```
#dwp-create <goal>
#dwp-execute
```

## หมายเหตุ

Windsurf อ่านไฟล์ขั้นตอนและดำเนินลูป Deep Work Plan แบบลำดับเต็มรูปแบบ
