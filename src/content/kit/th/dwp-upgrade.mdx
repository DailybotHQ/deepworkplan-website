# dwp-upgrade

ดูแลให้สกิล Deep Work Plan ที่ติดตั้งไว้และมาตรฐานที่ประกาศเป็นปัจจุบันอยู่เสมอด้วยความยินยอมอย่างชัดแจ้ง

## หน้าที่การทำงาน

 จะตรวจสอบรีลีสต้นทางเพื่อหารุ่นใหม่กว่าของชุดสกิลและมาตรฐาน โดยจะรายงานความแตกต่าง แสดงการดัดแปลงในเครื่อง กำหนดให้ต้องได้รับการอนุมัติอย่างชัดเจนก่อนดำเนินการเปลี่ยนแปลง และติดตั้งแท็กเวอร์ชันเสถียรโดยไม่เปลี่ยนแปลงแผนงานที่มีอยู่ใน 

## การใช้งาน



## พฤติกรรม

1. **ตรวจสอบ (อ่านอย่างเดียว)** — อ่านเวอร์ชันที่ติดตั้งจาก  และค้นหาแท็ก git ต้นทางสำหรับรีลีสที่เสถียรล่าสุด รายงานเวอร์ชันปัจจุบันเทียบกับเวอร์ชันล่าสุด
2. **ความยินยอม** — แสดงการแก้ไขหรือการดัดแปลงในเครื่องผ่าน diff โดยจะไม่ดาวน์โหลดหรือเขียนทับไฟล์โดยไม่ได้รับการยืนยันอย่างชัดเจน
3. **อัปเกรด** — ติดตั้งแท็กที่เสถียรลงใน  เติมเต็มแอดออนที่กำหนดค่าไว้ใน  และปรับความสอดคล้องของ harness
4. **รักษาประวัติ** — แผนงาน หลักฐาน และบันทึกที่มีอยู่ภายใต้  เป็นประวัติที่ไม่สามารถแก้ไขได้ และจะไม่ถูกเปลี่ยนแปลงหรือย้ายในระหว่างการอัปเกรด
