# dwp-resume

ทำงานต่อ Deep Work Plan ที่ถูกขัดจังหวะจากบันทึกที่คงทน

<CmdResume lang="th" class="not-prose my-8" />

## สิ่งที่มันทำ

`dwp-resume` ดำเนินแผนที่ถูกขัดจังหวะต่ออย่างปลอดภัยจากสิ่งที่อยู่ใน workspace เพียงอย่างเดียว โดยไม่ดำเนินการซ้ำ มันสร้างสถานะขึ้นใหม่อย่างกำหนดผลได้จาก `journal.ndjson` และ `contract.json` อ่านแพ็กเก็ตส่งมอบงานที่ค้างอยู่ แล้วดำเนินต่อจาก task แรกที่ยังไม่เสร็จ

## วิธีใช้

```
/dwp-resume [plan]
```

## พฤติกรรม

1. **อ่านบันทึก:** ตรวจดู `contract.json` และ `journal.ndjson` ภายใต้ `.dwp/plans/PLAN_<id>_<slug>/`
2. **ฉายสถานะ:** รัน `ledger.py project` เพื่อสร้าง `state.json` ใหม่อย่างกำหนดผลได้จากเจอร์นัลแบบเพิ่มต่อท้ายเท่านั้น เมื่อข้อมูลไม่ตรงกันจะยึดตามเจอร์นัล
3. **นำเข้าการส่งมอบงาน:** ตรวจหาแพ็กเก็ตส่งมอบงานของ swarm ที่ค้างอยู่ (`dwp-handoff-v1`) เพื่อกู้คืนเจตนาที่กำลังดำเนินอยู่ เกตที่ยังไม่ได้ยืนยัน และคำขอถึง peer ที่ยังเปิดอยู่
4. **ตรวจรอยต่อ:** ตรวจสถานะ git และรัน smoke check บนส่วนที่ถูกแตะต้องก่อนทำงานต่อ
5. **ดำเนินต่อ:** ดำเนิน task แรกที่ยังเปิดอยู่ผ่านลูปการดำเนินงานมาตรฐาน แผน v5 แบบเดิมจะดำเนินต่อด้วยลำดับงาน `PROGRESS.md` ที่บันทึกไว้โดยไม่บังคับย้ายรุ่น

## ชื่อแทน
