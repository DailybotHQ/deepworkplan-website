# DeepWorkPlan Vim

**DeepWorkPlan Vim** คือตัวแก้ไขบนเทอร์มินัลสำหรับ Deep Work Plan: คอนฟิก Neovim สำหรับผู้คนและเอเจนต์เขียนโค้ดที่ทำงานบนเทอร์มินัล แผนของคุณ เอกสารของคุณ และดัชนีของทุกคำสั่งอยู่ห่างเพียงการกดคีย์เดียว

นี่เป็นผลิตภัณฑ์แยกต่างหากและเป็นทางเลือก ไม่ติดตั้งและไม่ต้องใช้สกิล Deep Work Plan และไม่ได้เป็นส่วนหนึ่งของการเริ่มต้นใช้งาน DWP v6 คุณเพิ่มมันลงในเครื่องแยกต่างหากได้ และมันทำงานเป็นตัวแก้ไขไม่ว่าจะมีแผนหรือไม่

## ทำไมต้องมีตัวแก้ไขบนเทอร์มินัลสำหรับ Deep Work Plan

Deep Work Plan คือโฟลเดอร์ Markdown ภายใต้ `.dwp/plans/` ประกอบด้วยเป้าหมาย งานย่อยแบบอะตอม ประตูตรวจสอบ และบันทึกที่ต่อเนื่อง ผู้คนตรวจทาน เอเจนต์ลงมือทำ และทั้งสองฝ่ายมักทำสิ่งนี้บนเทอร์มินัล ตัวแก้ไขที่สร้างมาเพื่องานนี้เก็บสามอย่างไว้ใกล้ตัว: ตัวแผนเอง เอกสารรอบ ๆ แผน และคีย์ที่พาคุณเคลื่อนไปมาระหว่างทั้งสอง

DeepWorkPlan Vim คือตัวแก้ไขนั้น เป็นคอนฟิก Neovim ที่คัดสรรมาอย่างดี — เซิร์ฟเวอร์ภาษา การเติมโค้ดอัตโนมัติ linting การจัดรูปแบบ การค้นหาแบบคลุมเครือ ต้นไม้ไฟล์ และธีมสีที่คัดมา โหลดแบบเลื่อนเวลา — บวกกับหน้าจอไม่กี่อย่างที่ทำให้มันเป็นตัวแก้ไขสำหรับ Deep Work Plan

## ทัวร์: ดัชนีคำสั่งที่ไม่มีวันล้าสมัย

กด `SPC h h` (Space คือคีย์ leader) หรือรัน `:DwpCommands` แล้วตัวแก้ไขจะแสดงรายการการแมปคีย์ทุกรายการที่มี พร้อมคำอธิบายหนึ่งบรรทัด รายการนี้สร้างจากการแมปคีย์ที่ใช้งานอยู่ ดังนั้นการแมปที่นิยามไว้ที่ไหนก็ตามจะปรากฏในดัชนีโดยไม่ต้องลงทะเบียน และดัชนีจะไม่ล้าสมัย

นั่นคือทัวร์ทั้งหมด: เปิด `nvim` แล้วกด Space, `h`, `h`

## สิ่งที่คุณจะได้รับ

ห้าฟีเจอร์ แต่ละอย่างห่างเพียงการกดคีย์เดียว

| ฟีเจอร์ | คีย์ | ทำอะไร |
|---|---|---|
| ดัชนีคำสั่งที่สร้างอัตโนมัติ | `SPC h h` | ทุกการแมปในคอนฟิก สร้างจากการแมปคีย์ที่ใช้งานอยู่ |
| ท่าทางแบบ VS Code | `<C-a>`, `SPC y` | เลือกทั้งไฟล์ด้วยคีย์เดียว และคัดลอกไปยังคลิปบอร์ดของระบบ `y` ธรรมดาก็คัดลอกไปที่นั่นเช่นกัน เพราะคลิปบอร์ดใช้ร่วมกันทั้งระบบ |
| ตัวเรียกดูแผนของ Deep Work Plan | `SPC P` | แถบด้านข้างที่ครอบคลุมแผนในรีโพซิทอรีของคุณ จัดกลุ่มตามสถานะพร้อมแถบความคืบหน้า และตัวอ่านสำหรับแผนหนึ่ง ๆ |
| ตัวดู Markdown | `SPC m p`, `SPC m r` | ดูตัวอย่าง Markdown ในเบราว์เซอร์ หรือแสดงผลในบัฟเฟอร์ |
| ตัวติดตั้งบรรทัดเดียว | — | ตัวติดตั้งที่ครบในตัวสำหรับ macOS, Linux และ WSL พร้อมขั้นตอนแบบแมนนวลที่มีเอกสารสำหรับ Windows |

## ดูแผนโดยไม่ต้องออกจากตัวแก้ไข

`SPC P`, `:DwpPlans` หรือการคลิกที่ส่วนของแถบสถานะ จะเปิดแถบด้านข้างของแผน ครอบคลุมทุกโฟลเดอร์ `.dwp/plans/` ในไดเรกทอรีปัจจุบันและไดเรกทอรีคอนฟิกของ Neovim และจัดกลุ่มแผนโดยเริ่มจากแผนที่ต้องการความสนใจมากที่สุด ในตัวแก้ไข ป้ายกำกับคือ `Working`, `Needs attention`, `Ready`, `Not started` และ `Done` แต่ละแผนแสดงแถบความคืบหน้า

กด Enter บนแผนเพื่อเปิดตัวอ่าน: เป้าหมายในประโยคเดียว สถานะและความคืบหน้า รายการงานที่ทำเครื่องหมายงานปัจจุบัน และทางลัดด้วยภาษาที่เข้าใจง่ายไปยังไฟล์ของแผนเอง แถบสถานะแสดงแผนที่ใช้งานอยู่แบบสด และหน้าจอเริ่มต้นแสดงสามอันดับแรก หน้าจอเหล่านี้อธิบายแผน และไม่เขียนอะไรลงใน `.dwp/` เลย

หากต้องการอ่านไฟล์ Markdown ของแผนที่เดิม `SPC m p` จะแสดงตัวอย่างบัฟเฟอร์ปัจจุบันในเบราว์เซอร์ และ `SPC m r` จะแสดงผลภายในบัฟเฟอร์ ทั้งสองใช้ได้เฉพาะในบัฟเฟอร์ Markdown

## การติดตั้ง

การติดตั้งทั้งหมดคือบรรทัดเดียว เมื่อรันจะติดตั้งสิ่งที่รีโพซิทอรีส่งมอบอยู่ใน `main` ในตอนนี้

<VimInstall lang="th">

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

</VimInstall>

ตัวติดตั้งทำตามลำดับดังนี้:

1. ตรวจระบบปฏิบัติการและตัวจัดการแพ็กเกจของคุณ และติดตั้ง git, curl และตัวแปลภาษา Lua หากขาดอย่างใดอย่างหนึ่ง
2. ถามก่อนแตะต้องคอนฟิก Neovim ที่มีอยู่ หากรันผ่านไปป์โดยไม่มีเทอร์มินัล มันจะหยุดและไม่เปลี่ยนแปลงอะไร
3. โคลนรีโพซิทอรีไปที่ `~/.config/nvim` หรืออัปเดตหากมีอยู่แล้ว
4. รัน `lua install.lua` ของรีโพซิทอรีเอง
5. ติดตั้งปลั๊กอินแบบ headless จึงไม่ต้องออกแล้วเปิดใหม่

หากต้องการอ่านสคริปต์ก่อน ให้ดาวน์โหลดด้วย `curl -fsSL https://deepworkplan.com/vim/install.sh -o install.sh` เปรียบเทียบ SHA-256 ของมันกับค่าที่แสดงด้านบน อ่านให้เรียบร้อย แล้วจึงรัน `bash install.sh`

## ข้อกำหนดและแพลตฟอร์ม

- Neovim 0.12 หรือใหม่กว่า ติดตั้ง Neovim ก่อน ตัวติดตั้งไม่ได้ติดตั้งให้
- Lua: `lua`, `lua5.4` หรือ `luajit` ตัวติดตั้งจะเพิ่มให้หนึ่งตัวหากไม่มี
- macOS, Linux และ WSL รันคำสั่งบรรทัดเดียวได้ สำหรับ Windows มีขั้นตอนแบบแมนนวลใน README ของรีโพซิทอรี: ติดตั้ง Neovim ด้วย winget โคลนรีโพซิทอรีไปที่ `%LOCALAPPDATA%\nvim` แล้วรัน `lua install.lua` จาก Git Bash
- ใช้สัญญาอนุญาต GPL-3.0: ใช้ ศึกษา และแก้ไขได้อย่างอิสระ

## อัปเดต ตรึงเวอร์ชัน และถอนการติดตั้ง

รันตัวติดตั้งอีกครั้งเพื่ออัปเดต มันเป็น idempotent: เช็กเอาต์ DeepWorkPlan Vim ที่มีอยู่จะถูกอัปเดตด้วย fast-forward และการเปลี่ยนแปลงในเครื่องจะไม่ถูกรีเซ็ต

หากต้องการติดตั้งแบรนช์ แท็ก หรือคอมมิตที่ระบุ ให้ตั้งค่า `DWP_VIM_REF` แท็กรุ่นเก่าอาจไม่มีฟีเจอร์ทั้งหมดที่อธิบายในหน้านี้

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | DWP_VIM_REF=<branch-tag-or-commit> bash
```

หากต้องการถอนการติดตั้ง ให้รัน `lua delete.lua` จากไดเรกทอรีคอนฟิก มันจะลบคอนฟิก ปลั๊กอิน ข้อมูล Mason แคชและสถานะ และสำเนาฟอนต์ที่ตัวติดตั้งทำไว้ และปล่อยไบนารี Neovim กับแพ็กเกจระบบของคุณไว้ตามเดิม

```bash
cd ~/.config/nvim && lua delete.lua
```

## คำถาม

### มันจะเขียนทับคอนฟิก Neovim ของฉันไหม?

ไม่ หากคุณไม่อนุมัติ เมื่อพบคอนฟิกที่ไม่ใช่ DeepWorkPlan Vim การรันแบบโต้ตอบจะถามก่อนย้ายไปที่ `~/.config/previous-deepworkplan-vim` หากไม่มีเทอร์มินัล หรือพาธสำรองนั้นมีอยู่แล้ว มันจะหยุดและไม่เปลี่ยนแปลงอะไร

### ใช้บน Windows ได้ไหม?

คำสั่งบรรทัดเดียวใช้ไม่ได้บน Windows ให้ใช้ขั้นตอนแบบแมนนวลใน README ของรีโพซิทอรี หรือรันคำสั่งบรรทัดเดียวภายใน WSL

### ต้องมี Deep Work Plan ถึงจะใช้ได้ไหม?

ไม่ มันเป็นตัวแก้ไขก่อนเป็นอันดับแรก ไม่ติดตั้งและไม่ต้องใช้สกิล Deep Work Plan ตัวเรียกดูแผนเพียงแต่ไม่มีอะไรจะแสดงจนกว่าจะมีโฟลเดอร์ `.dwp/plans/`

### เอเจนต์เขียนโค้ดใช้มันอย่างไร?

สร้างมาเพื่อผู้คนและเอเจนต์เขียนโค้ดที่อยู่บนเทอร์มินัล การแมปคีย์ของมันถูกตรึงด้วยการทดสอบสัญญา ความจำของกล้ามเนื้อและสิ่งที่เอเจนต์คาดหวังจึงยังอยู่หลังการอัปเดต

### ฉันจะได้เวอร์ชันไหน?

ตัวติดตั้งจะติดตั้ง `main` เว้นแต่คุณตั้งค่า `DWP_VIM_REF` หน้านี้อธิบายสิ่งที่มันติดตั้ง และไม่ผูกฟีเจอร์ใดกับหมายเลขเวอร์ชัน

### ใช้สัญญาอนุญาตอะไร และมาจากไหน?

GPL-3.0 พัฒนาต่อจาก mu-vim ของ Andrés M Prieto และเครดิตยังคงอยู่ในรีโพซิทอรี
