# ส่วนเสริม DeepWorkPlan Vim

**DeepWorkPlan Vim** คือตัวแก้ไขเทอร์มินัลของ Deep Work Plan: การตั้งค่า Neovim ชุดหนึ่ง (นี่คือตัวแก้ไขเอง ไม่ใช่ไฟล์ของที่เก็บ) ที่วางพื้นผิวการทำงานของวิธีการไว้ห่างเพียงการกดปุ่มเดียว ขณะที่รายการอื่นใน kit ติดตั้ง harness ลงในที่เก็บ ส่วนเสริมนี้ติดอาวุธให้มนุษย์ — และเอเจนต์ใดก็ตามที่ขับเคลื่อน Neovim แบบ headless — ด้วยตัวแก้ไขที่พูด DWP ได้ดั้งเดิม

ต้องการ **Neovim 0.12 หรือใหม่กว่า** ทำงานบน **macOS และ Linux** (Windows รองรับผ่านเส้นทางแมนนวลที่มีเอกสารกำกับ) และเผยแพร่ภายใต้สัญญาอนุญาต **GPL-3.0** — ใช้ ศึกษา และแก้ไขได้อย่างเสรี

## มันเพิ่มอะไร

| # | คุณสมบัติ | มันทำอะไร | การจับคู่ปุ่ม |
|---|---------|--------------|---------|
| F1 | **ดัชนีคำสั่งแบบสร้างอัตโนมัติ** | ทั้งตัวแก้ไขจัดเป็นรายการ: ทุกคำสั่งพร้อมการจับคู่ปุ่มและคำอธิบายบรรทัดเดียว สร้างจากการตั้งค่าที่มีชีวิต ดัชนีจึงเหลื่อมจากตัวแก้ไขไม่ได้ | `SPC h h` |
| F2 | **ท่าทางแบบ VS Code** | เลือกทั้งหมด คัดลอก และ yank ไปยังคลิปบอร์ด บนคอร์ดที่กล้ามเนื้อจำได้แล้ว | `<C-a>`, `y`, `<leader>y` |
| F3 | **ตัวเรียกดู Deep Work Plan** | เปิดแผนที่ขับเคลื่อนที่เก็บ — งาน ประตูตรวจสอบ และสถานะความเสร็จ — โดยไม่ต้องออกจากตัวแก้ไข | `SPC P` |
| F4 | **ตัวดู Markdown** | อ่าน Markdown อย่างที่เอเจนต์อ่าน: พรีวิวที่เรนเดอร์แล้ว หรือซอร์สดิบเพื่อความละเอียดของการคัดลอกวาง | `SPC m p`, `SPC m r` |
| F5 | **ตัวติดตั้งหนึ่งบรรทัด** | `install.sh` แบบขอความยินยอมก่อนสำหรับ macOS และ Linux; เส้นทางแมนนวลที่มีเอกสารกำกับดูแล Windows | `curl -fsSL https://deepworkplan.com/vim/install.sh \| bash` |

## การติดตั้ง

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

<VimInstall lang="th" />

ตัวติดตั้งเป็นแบบ **ขอความยินยอมก่อน**: การตั้งค่า Neovim ที่มีอยู่แล้วซึ่งเป็นของผู้อื่นจะไม่ถูกเขียนทับเด็ดขาด ถ้าถูกส่งผ่านไปป์โดยไม่มีเทอร์มินัล มันจะหยุดพร้อมคำแนะนำโดยไม่แตะต้องสิ่งใด ในโหมดโต้ตอบ มันจะถามก่อนย้ายการตั้งค่าที่มีอยู่ออกไปด้านข้าง ปลั๊กอินติดตั้งแบบ headless ตั้งแต่การเปิดครั้งแรก — ไม่มีพิธีปิดแล้วเปิดใหม่

Windows ไม่ใช่ปลายทางของ `curl | bash` เส้นทางแมนนวลที่มีเอกสารกำกับ (winget บวก Git Bash หรือ WSL) อยู่ใน README ของที่เก็บ

## ใช้เมื่อไหร่

| สัญญาณ | การกระทำ |
|--------|--------|
| นักพัฒนาอาศัยอยู่ในเทอร์มินัลและขับเคลื่อนที่เก็บด้วยแผน | **เสนอ** ส่วนเสริมนี้ |
| การ execute DWP ระยะยาวที่ตัวเรียกดูแผน (`SPC P`) ทำให้สถานะมองเห็นได้ตลอด | **แนะนำ** |
| ตัวแก้ไขของนักพัฒนาตั้งค่าไว้แล้วและไม่อาจต่อรอง | **ข้าม** — ส่วนเสริมนี้เป็น opt-in ตามการออกแบบ |
| ทีมใช้แต่ Windows โดยไม่มี WSL | **ข้าม** หรือชี้ไปที่เส้นทางแมนนวลที่มีเอกสารกำกับ |
