# อะแดปเตอร์ Google Gemini

Google Gemini รองรับ DWP ผ่านขั้นตอนคำสั่งแบบ markdown

## ระดับการรองรับ

**สมบูรณ์** (ผ่านการทดสอบการติดตั้ง) — ทุกคำสั่ง dwp-* รันจากไฟล์ขั้นตอนการทำงาน เส้นทางได้รับการยืนยันโดยชุดการทดสอบอัตโนมัติ เวิร์กโฟลว์พฤติกรรมทำงานบนเส้นฐานตามลำดับ ต้องใช้การเรียกใช้เครื่องมือและการเข้าถึงไฟล์ในพื้นที่ทำงาน

## การติดตั้ง

คำสั่ง DWP อยู่ในรูปขั้นตอนแบบ markdown ที่ agent อ่านเมื่อมีการเรียกใช้

## การเรียกใช้

ใช้คำนำหน้า `#`

```
#dwp-create <goal>
#dwp-execute
```

## หมายเหตุ

Gemini อ่านไฟล์ขั้นตอนและดำเนินลูป Deep Work Plan แบบลำดับเต็มรูปแบบ
