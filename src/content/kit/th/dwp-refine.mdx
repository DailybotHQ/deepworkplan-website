# dwp-refine

ปรับแต่ง Deep Work Plan ที่มีอยู่

<CmdRefine lang="th" class="not-prose my-8" />

## สิ่งที่มันทำ

`dwp-refine` แก้ไขแผนที่มีอยู่ มันเพิ่ม ลบ หรือจัดลำดับ task ใหม่ได้ โดยรักษางานที่เสร็จแล้วและอัปเดตตาราง task

## วิธีใช้

```
/dwp-refine [plan]
```

## พฤติกรรม

1. อ่านแผนที่มีอยู่
2. เพิ่ม ลบ หรือจัดลำดับ task ใหม่
3. รักษางานที่เสร็จแล้ว
4. อัปเดตตาราง task
5. บันทึกว่ามีอะไรเปลี่ยนและเพราะเหตุใด

## การเลื่อนขั้นแผน Lite เป็น Full

`/dwp-refine promote {plan_name}` เปลี่ยนรูปแบบตัวแทนที่เป็นทางการของแผน Lite จากบันทึก task แบบอินไลน์ใน README ไปเป็นไฟล์แยกต่อ task โดยรักษางานที่เสร็จแล้วและ ID ของ task ไว้โดยไม่เปลี่ยนขอบเขต การเลื่อนขั้นเกี่ยวข้องกับรูปแบบตัวแทนเท่านั้น — มันไม่เรียก execute เลย แผน Full จะไม่ถูกลดขั้นกลับไปเป็น Lite โดยอัตโนมัติ

## ชื่อแทน

- `dwp:refine`
