# dwp-execute

ดำเนิน Deep Work Plan ที่มีอยู่

<CmdExecute lang="th" class="not-prose my-8" />

## สิ่งที่มันทำ

`dwp-execute` รันแผนที่มีอยู่ทีละ task มันอ่านแผนทั้งหมด ดำเนินแต่ละ task ตามลำดับ อัปเดต `PROGRESS.md` และทำเครื่องหมายสถานะความเสร็จของแต่ละ task

## วิธีใช้

```
/dwp-execute
/dwp-execute [plan]
/dwp-execute [plan] trust
```

## พฤติกรรม

1. อ่านแผนทั้งหมดก่อนเริ่ม
2. `ledger.py ready` & `ledger.py start` -> ดำเนิน task ตามลำดับ
3. `ledger.py gate` -> `observed` evidence; อัปเดต `PROGRESS.md` หลังแต่ละ task
4. `parallel_safe` delegation; ทำเครื่องหมายสถานะ task อย่างแม่นยำ
5. `ledger.py complete` & Final Review; หยุดและถามเมื่อติดขัด

## ชื่อแทน

- `dwp:execute`
