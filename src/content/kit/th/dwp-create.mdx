# dwp-create

สร้าง Deep Work Plan ใหม่จากเป้าหมายระดับสูง

<CmdCreate lang="th" class="not-prose my-8" />

## สิ่งที่มันทำ

`dwp-create` รับเป้าหมายระดับสูงมาแล้วเปลี่ยนเป็น Deep Work Plan ที่มีโครงสร้างและดำเนินการได้ มันวิเคราะห์ข้อกำหนด ถามคำถามเพื่อความชัดเจนหากคลุมเครือ และทำให้แผน Lite หรือ Full เป็นรูปธรรมโดยตรงภายใต้ `.dwp/plans/PLAN_<id>_<slug>/`

## วิธีใช้

```
/dwp-create <goal>
/dwp-create trust lite <goal>
/dwp-create <goal> full trust
```

## โหมดและตัวเลือกขอบเขต

ตัวเลือกขอบเขตกำหนดพฤติกรรมการทบทวนและรูปแบบของแผน โดยวางเป็นโทเค็นไว้ที่ต้นหรือท้ายคำสั่งในลำดับใดก็ได้:

- **โหมดการทบทวน:**
  - **Guided (ค่าเริ่มต้น):** ทำให้ข้อเสนอแผน Lite ที่ดำเนินการได้เป็นรูปธรรม แสดงสัญญาณที่สังเกตได้และเหตุผลในการเลือกรูปแบบ แล้วถามว่าจะเก็บไว้เป็น Lite เลื่อนขั้นเป็น Full แก้ไข หรือหยุด
  - **Trust (`trust` หรือ `auto`):** ข้ามการทบทวนและไปยังแผนที่ได้รับการอนุมัติล่วงหน้าและพร้อมรันโดยตรง
- **รูปแบบที่ต้องการ:**
  - **`lite`:** แสดงความต้องการแผนแบบไฟล์เดียวที่กระชับใน `README.md` พร้อมบันทึก task ที่มีจุดยึด (`#task-N`)
  - **`full`:** แสดงความต้องการไฟล์ task ที่แยกส่วนและมีหมายเลข (`N.task_<slug>.md`)
  - การระบุทั้ง `lite` และ `full` ถือเป็นความขัดแย้งที่ชัดแจ้ง
- **ตัวสิ้นสุด:** `--` ยุติการแยกวิเคราะห์ตัวเลือก ทุกอย่างหลัง `--` จะถูกตีความเป็นบริบทเป้าหมายตามตัวอักษร

## พฤติกรรม

1. **การวิเคราะห์ข้อกำหนด:** ตรวจดูบริบทของ repository สถาปัตยกรรม และคำสั่งทดสอบที่มีเอกสารกำกับ
2. **การทำให้ชัดเจน:** ถามคำถามเพื่อความชัดเจนหากขอบเขตหรือข้อกำหนดคลุมเครือ
3. **การจัดสรรแบบเพิ่มขึ้นทางเดียว:** จัดสรรชื่อโฟลเดอร์แบบเติมศูนย์ `PLAN_<id>_<slug>/` ภายใต้ `.dwp/plans/` โดยใช้ `.next-plan-id` ภายใต้การล็อกไฟล์แบบ POSIX (`fcntl`) ID ตัวเลขเพิ่มขึ้นทางเดียวและไม่ถูกนำกลับมาใช้ซ้ำ
4. **การทำสัญญาให้เป็นรูปธรรม:** รัน `ledger.py materialize` เพื่อเขียน `manifest.json` ประทับ `contract.json` แบบอ้างอิงตามเนื้อหา (รุ่น v7 พร้อมเครื่องหมาย task `parallel_safe`) และบันทึกเหตุการณ์ `approval` เริ่มต้น
5. **Final Review:** แผนปิดท้ายด้วย task Final Review ห้าส่วนที่บังคับ (การตรวจความปลอดภัยพร้อมการรีวิวในเครื่องที่จำเป็น การตรวจสอบสถานะสุดท้าย การกระทบยอดเรื่อง skill การกระทบยอดเอกสาร และการปิดงาน)

## ชื่อแทน

- `dwp:create`
