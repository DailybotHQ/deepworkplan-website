# dwp-resume

Reanuda un Deep Work Plan interrumpido a partir de registros duraderos.

<CmdResume lang="es" class="not-prose my-8" />

## Qué hace

`dwp-resume` continúa de forma segura un plan interrumpido únicamente a partir de los artefactos del espacio de trabajo sin ejecución duplicada. Reconstruye determinísticamente el estado a partir de `journal.ndjson` y `contract.json`, lee paquetes de relevo pendientes y continúa desde la primera tarea incompleta.

## Uso

```
/dwp-resume [plan]
```

## Comportamiento

1. **Leer registros:** inspecciona `contract.json` y `journal.ndjson` bajo `.dwp/plans/PLAN_<id>_<slug>/`.
2. **Proyectar estado:** ejecuta `ledger.py project` para regenerar determinísticamente `state.json` desde el diario de solo adición. Cualquier discrepancia se resuelve a favor del diario.
3. **Ingestión de relevo:** comprueba paquetes de relevo de enjambre pendientes (`dwp-handoff-v1`) para recuperar la intención en vuelo, puertas no verificadas y peticiones abiertas entre pares.
4. **Verificar costura:** comprueba el estado de git y ejecuta pruebas de humo en las superficies tocadas antes de reanudar.
5. **Continuar:** ejecuta la primera tarea abierta mediante el bucle de ejecución estándar. Los planes v5 heredados continúan utilizando su flujo registrado en `PROGRESS.md` sin migración forzada.

## Alias

- `dwp:resume`
