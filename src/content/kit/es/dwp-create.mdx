# dwp-create

Crea un nuevo Deep Work Plan a partir de un objetivo de alto nivel.

<CmdCreate lang="es" class="not-prose my-8" />

## Qué hace

`dwp-create` toma un objetivo de alto nivel y lo convierte en un plan estructurado. Analiza el objetivo, formula preguntas aclaratorias si hace falta, descompone el trabajo en tareas secuenciales y escribe los archivos del plan.

## Uso

```
/dwp-create <goal>
```

## Modos

`dwp-create` usa por defecto el modo **guiado**: reúne contexto, ejecuta el análisis, y materializa directamente un plan Lite — una propuesta compacta que ya es ejecutable, no un borrador desechable — **te lo muestra y te pregunta si quieres conservarlo como Lite, promoverlo a un plan Full de archivo por tarea, editarlo o detenerte** — de modo que siempre lees el plan real antes de decidir. Es el valor por defecto recomendado, sobre todo las primeras veces.

Añade **`trust`** (o `auto`) como última palabra para omitir esa revisión — el agente pasa directo a un plan preaprobado y listo para ejecutar (Lite o Full, elegido por las mismas señales):

```
/dwp-create <goal> trust
```

El modo trust es el atajo para usuarios avanzados una vez que confías en el flujo; el modo guiado mantiene a una persona en el bucle por defecto.

## Comportamiento

1. Analiza el objetivo y el contexto del repositorio.
2. Formula preguntas aclaratorias si es ambiguo.
3. Materializa el plan directamente bajo `.dwp/plans/PLAN_<name>/` — un plan Lite por defecto, o Full para trabajos más grandes (en modo guiado, revísalo y elige conservarlo como Lite, promoverlo a Full, editarlo o detenerte).
4. Descompone en tareas secuenciales y escribe el README, los archivos de tarea y PROGRESS.
5. Termina con el Final Review (pase de seguridad, validación de estado final, reconciliación de skills).
