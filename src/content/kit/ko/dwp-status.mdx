# dwp-status

Deep Work Plan을 실행하지 않고 상태를 보고합니다.

<CmdStatus lang="ko" class="not-prose my-8" />

## 하는 일

`dwp-status`는 계약상 엄격하게 읽기 전용입니다. 진행 상황, 현재 차단 요소, 체크포인트, 리소스 엔벨로프를 요약하며 어떤 파일도 변경하지 않습니다.

## 사용법

```
/dwp-status                      # list and summarize all plans
/dwp-status [plan]               # report details for a specific plan
```

## 동작

1. **4가지 수명 주기 차원:** 형식(`lite` 또는 `full`), 구체화 상태(`materializing`, `ready`, `promoting`), 검토 승인(`pending`, `approved`, `pre_approved`), 실행 진행(`pending`, `in_progress`, `blocked`, `completed`)을 보고합니다.
2. **리포지토리 전체 개요:** 인수 없이 호출하면 `.dwp/plans/` 아래의 모든 계획을 완료율, 현재 task 위치, 차단 요소 요약과 함께 나열합니다.
3. **리소스 엔벨로프:** 추적되는 차원(`wall_clock`, 재시도, 디스패치, 지출, 토큰)별로 사용량과 상한을 표시하고, 한도가 실제로 강제되는지 권고 수준인지 알려 줍니다.
4. **차단 요소 진단:** `state.json.blocked`의 현재 차단 요소 세부 정보를 표준 에스컬레이션 분류(등급 C1–C7)에 따라 보여 줍니다.
5. **위임 관찰:** 진행 중이거나 완료된 하위 에이전트 위임과 기록된 피어 교류를 요약합니다.

## 별칭
