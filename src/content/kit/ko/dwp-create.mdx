# dwp-create

상위 수준 목표로부터 새 Deep Work Plan을 생성합니다.

<CmdCreate lang="ko" class="not-prose my-8" />

## 하는 일

`dwp-create`는 상위 수준 목표를 받아 구조화된 계획으로 바꿉니다. 목표를 분석하고, 필요하면 명확히 하는 질문을 하며, 작업을 순차적 task로 분해한 뒤 계획 파일을 작성합니다.

## 사용법

```
/dwp-create <goal>
```

## 모드

`dwp-create`는 기본적으로 **가이드(guided)** 모드입니다. 컨텍스트를 수집하고, 분석을 실행하고, Lite 계획을 직접 구체화합니다 — 이미 실행 가능한 간결한 제안이며, 버릴 초안이 아닙니다 — **그것을 보여 주고, Lite로 유지할지, task 파일 기반의 Full 계획으로 승격할지, 편집할지, 중단할지 묻습니다** — 그래서 결정하기 전에 항상 실제 계획을 읽게 됩니다. 이것이 권장 기본값이며, 특히 처음 몇 번에 좋습니다.

마지막 단어로 **`trust`**(또는 `auto`)를 덧붙이면 이 검토를 건너뜁니다 — 에이전트가 곧바로 사전 승인된, 바로 실행 가능한 계획(같은 신호로 선택된 Lite 또는 Full)으로 진행합니다.

```
/dwp-create <goal> trust
```

trust 모드는 흐름을 신뢰하게 된 뒤의 파워 유저 단축 경로이고, 가이드 모드는 기본적으로 사람을 루프 안에 둡니다.

## 동작

1. 목표와 리포지토리 컨텍스트를 분석합니다.
2. 모호하면 명확히 하는 질문을 합니다.
3. `.dwp/plans/PLAN_<name>/` 아래에 계획을 직접 구체화합니다 — 기본은 Lite 계획이고, 더 큰 작업은 Full 계획입니다(가이드 모드에서는 검토하고 Lite 유지, Full 승격, 편집, 중단 중에서 선택합니다).
4. 순차적 task로 분해하고 README, task 파일, PROGRESS를 작성합니다.
5. Final Review(보안 점검, 최종 상태 검증, 스킬 조정)로 끝맺습니다.

## 별칭

- `dwp:create`
