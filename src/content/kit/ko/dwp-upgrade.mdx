# dwp-upgrade

명시적인 동의를 바탕으로 설치된 Deep Work Plan 스킬과 선언된 표준을 최신 상태로 유지합니다.

## 기능

는 업스트림 릴리스를 점검하여 스킬 팩 및 표준의 최신 버전을 확인합니다. 차이점을 보고하고, 로컬 적응 사항을 표시하며, 변경하기 전에 명시적인 승인을 요구하고,  아래의 기존 계획을 수정하지 않고 고정된 안정 릴리스 태그를 설치합니다.

## 사용법



## 동작 방식

1. **확인 (읽기 전용)** — 에서 설치된 버전을 읽고 최신 안정 릴리스의 업스트림 git 태그를 조회합니다. 현재 버전과 최신 버전을 비교 보고합니다.
2. **동의** — diff를 통해 로컬 수정 또는 적응을 표시합니다. 명시적인 확인 없이 파일을 다운로드하거나 덮어쓰지 않습니다.
3. **업그레이드** — 에 정확한 안정 태그를 설치하고, 의 구성된 애드온을 채우며, 하네스를 조정합니다.
4. **기록 보존** —  아래의 기존 계획, 증거 및 로그는 불변의 기록이며 업그레이드 중에 수정되거나 마이그레이션되지 않습니다.
