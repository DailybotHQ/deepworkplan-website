# dwp-refine

기존 Deep Work Plan을 정제합니다.

<CmdRefine lang="ko" class="not-prose my-8" />

## 하는 일

`dwp-refine`은 기존 계획을 수정합니다. 완료된 작업을 보존하고 task 표를 갱신하면서 task를 추가, 제거, 재배열할 수 있습니다.

## 사용법

```
/dwp-refine [plan]
```

## 동작

1. 기존 계획을 읽습니다.
2. task를 추가, 제거, 재배열합니다.
3. 완료된 작업을 보존합니다.
4. task 표를 갱신합니다.
5. 무엇이 왜 바뀌었는지 기록합니다.

## Lite 계획을 Full로 승격하기

`/dwp-refine promote {plan_name}`은 Lite 계획의 권위 있는 표현을 README의 인라인 task 기록에서 task별 파일로 전환하며, 범위를 바꾸지 않고 완료된 작업과 task ID를 보존합니다. 승격은 표현 방식에만 관련됩니다 — execute를 호출하는 일은 결코 없습니다. Full 계획이 자동으로 Lite로 강등되지는 않습니다.

## 별칭

- `dwp:refine`
