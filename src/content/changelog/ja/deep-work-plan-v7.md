Deep Work Plan v7 は v6 の方法を維持します。契約が権威であり、追記専用のジャーナルが記憶であり、スケジューラが次に実行するものを決め、記録された証拠がタスクの基準を満たしたときにのみタスクが完了します。v7 は委任の能力を加え、その結果に対しても同じ規律を保ちます。

`agent_delegation` を付与した計画は、タスクを `parallel_safe` とマークして別のエージェントへ渡すことができます。委任先の応答は指示ではなくデータとして記録され、計画自身のゲートランナーが結果を観測するまで `asserted` のままです。`observed` の証拠を生成できるのはランナーだけなので、委任は完了の基準を下げることなく到達範囲を広げます。

4 つの任意アドオンが、委任を実用的な自律性に変えます。Herdr は、任意のマシン上のペインにいるエージェントへタスクを渡します。Agentkit は、すべてのターミナル向けコーディングエージェントの上に 1 つの `ak` コマンドを置き、既定で自律的に動作し、無効にもでき、範囲の限られたタスクを git worktree 内でヘッドレス実行します。Devcontainer は、SSH 鍵を一切含まない再現可能なコンテナを各リポジトリに提供します。DeepWorkPlan Vim は、計画ブラウザと Markdown ビューアを備えたターミナルエディタです。それぞれ独自のリポジトリを持つプロダクトにタグで固定されており、Deep Work Plan なしでも動作します。リポジトリはこれらを一つも使わなくても完全に準拠でき、`.dwp/config.json` のレジストリにどれが有効かが記録されます。

ベンチマークと学習モードは、各計画から得られた知見を記録し、後で分析できるようにします。リポジトリごとに 1 エージェントを割り当てた v7 オーケストレーター計画としてエコシステム全体の監査を実施したところ、v6 に対する挙動の退行は見つかりませんでした。パックのスイートはクリーンな環境で 807 件中 807 件が合格し、命令の読み込み量はフローごとに 0.1% から 3.9% 増加しました（パック全体では 4.6%）。これは両方のタグでバイト数として測定したもので、トークンとして推定したものではありません。

v7 はオーケストレーションと監査可能性における大きな前進ですが、完全なハンズオフの自律性にはまだ至っていません。ベンチマークと学習のループは、まだ v7 の計画を自動的には測定しておらず、エージェントの成果の非劣性も測定されていません。既存の計画は記録された世代を維持し、暗黙のうちに移行されることはありません。新しい計画は既定で v7 契約を使用します。

インストール済みスキルのリリースは **7.1.4** です。7.0.0 以降、安定しています。
