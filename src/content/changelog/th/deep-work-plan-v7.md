Deep Work Plan v7 คงวิธีการของ v6 ไว้ สัญญาคืออำนาจสูงสุด บันทึกแบบเพิ่มต่อท้ายอย่างเดียวคือหน่วยความจำ ตัวจัดตารางตัดสินว่าจะรันอะไรต่อไป และงานจะปิดได้ก็ต่อเมื่อหลักฐานที่บันทึกไว้ตรงตามเกณฑ์ของงานนั้น v7 เพิ่มความสามารถในการมอบหมายงาน และคงวินัยเดียวกันกับผลลัพธ์ที่ได้

แผนที่ให้สิทธิ์ `agent_delegation` สามารถทำเครื่องหมายงานเป็น `parallel_safe` แล้วส่งต่อให้เอเจนต์อื่นได้ คำตอบของผู้รับมอบหมายถูกบันทึกเป็นข้อมูล ไม่ใช่คำสั่ง และคงสถานะ `asserted` จนกว่าตัวรันเกตของแผนเองจะสังเกตเห็นผลลัพธ์ มีเพียงตัวรันเท่านั้นที่สร้างหลักฐาน `observed` ได้ การมอบหมายงานจึงขยายขอบเขตโดยไม่ลดมาตรฐานของการทำให้เสร็จ

แอดออนทางเลือกสี่รายการเปลี่ยนการมอบหมายงานให้เป็นความเป็นอิสระที่ใช้งานได้จริง Herdr ส่งงานให้เอเจนต์ในเพนบนเครื่องใดก็ได้ Agentkit วางคำสั่ง `ak` เพียงคำสั่งเดียวไว้เหนือเอเจนต์เขียนโค้ดบนเทอร์มินัลทั้งหมด โดยเปิดความเป็นอิสระเป็นค่าเริ่มต้นและปิดได้ และรันงานที่มีขอบเขตแบบไม่มีหน้าจอใน git worktree Devcontainer ให้แต่ละรีโพสิทอรีมีคอนเทนเนอร์ที่ทำซ้ำได้โดยไม่มีคีย์ SSH อยู่ภายในเป็นค่าเริ่มต้น (git ผ่าน SSH โดยใช้โฮสต์เอเจนต์ มีไฟล์คีย์เมื่อเลือกเปิดใช้งาน `[ssh] copy_keys` อย่างชัดเจนเท่านั้น) DeepWorkPlan Vim คือตัวแก้ไขบนเทอร์มินัลที่มีตัวเรียกดูแผนและตัวแสดง Markdown แต่ละรายการถูกตรึงด้วยแท็กกับผลิตภัณฑ์ที่มีรีโพสิทอรีของตนเอง และทำงานได้โดยไม่ต้องมี Deep Work Plan รีโพสิทอรีสอดคล้องครบถ้วนได้แม้ไม่ใช้รายการใดเลย และรีจิสทรีใน `.dwp/config.json` บันทึกว่าเปิดใช้รายการใดบ้าง

โหมดเบนช์มาร์กและบทเรียนบันทึกสิ่งที่แต่ละแผนสอนไว้ เพื่อให้วิเคราะห์ข้อค้นพบได้ภายหลัง การตรวจสอบระบบนิเวศทั้งหมด ซึ่งรันเป็นแผนผู้ประสานงาน v7 โดยใช้หนึ่งเอเจนต์ต่อหนึ่งรีโพสิทอรี ไม่พบการถดถอยด้านพฤติกรรมเมื่อเทียบกับ v6 ชุดทดสอบของแพ็กผ่าน 807 จาก 807 ในสภาพแวดล้อมที่สะอาด และปริมาณคำสั่งเพิ่มขึ้น 0.1% ถึง 3.9% ต่อโฟลว์ (4.6% สำหรับทั้งแพ็ก) วัดเป็นไบต์บนทั้งสองแท็ก ไม่ได้ประมาณเป็นโทเค็น

v7 เป็นก้าวสำคัญด้านการประสานงานและความสามารถในการตรวจสอบ แต่ยังไม่ใช่ความเป็นอิสระที่ไม่ต้องมีคนดูแลเลย รุ่น 7.2.0 ปิดช่องว่างที่การตรวจสอบนั้นพบ: เบนช์มาร์กและบทเรียนตอนนี้วัดแผน v7 ได้ การเริ่มงานก่อนที่ข้อกำหนดเบื้องต้นจะเสร็จสมบูรณ์จะถูกปฏิเสธ และชุดทดสอบทำงานแบบปิดผนึก (815 จาก 815 ในสภาพแวดล้อมที่สะอาด) ยังไม่ได้วัดว่าผลลัพธ์ของเอเจนต์ไม่ด้อยกว่าเดิม แผนเดิมคงรุ่นที่บันทึกไว้และจะไม่ถูกย้ายโดยปริยาย แผนใหม่ใช้สัญญา v7 เป็นค่าเริ่มต้น

รุ่น 7.6.0 (2026-10-11) แนะนำการประสานงานขนาดใหญ่: หนึ่งเลน (lane) ต่อหนึ่งรีโพสิทอรีหรือสายงาน การเลือกบัญชีตามโควตาที่เหลือ (`ak usage`, `ak pick`) การเปิดตัวแบบไม่ต้องเฝ้าดู และการเริ่มต้นใช้งานที่ตรวจพบแอดออนทุกตัว อัปเกรดตัวที่ใช้งานอยู่ และเสนอตัวที่เหมาะสม

รุ่น 7.7.0 (2026-10-12) มอบความเป็นอิสระแบบกลุ่ม (คู่มือ §17): ลูปความจุ (`shared/swarm.py`), แพ็กเก็ตการส่งต่องาน (`dwp-handoff-v1`), การสืบทอดตำแหน่งผู้นำพร้อมรอบยุคและการแยกส่วน, การร้องขอข้ามเลน, การจัดหมวดหมู่การยกระดับปัญหาตาม AGENT_PROTOCOL §7.5 (C1–C7: ตัดสินใจและบันทึกสิ่งอื่นทั้งหมด), มาตรฐานคุณภาพ (เกตคือสมมติฐาน ได้รับการตรวจสอบแล้วไม่ใช่แค่การอ้างสิทธิ์) และบทเรียนระเบียบวิธีจากแผนที่ดำเนินการแล้ว 313 แผนใน 23 รีโพสิทอรี ขีดจำกัดที่ทราบ: เจอร์นัล v7 ไม่มีเหตุการณ์เฉพาะสำหรับการส่งต่อเลนหรือการสืบทอดตำแหน่งผู้นำ (บันทึกเป็นการมอบหมายที่ถูกยกเลิกบวกกับการสังเกตการณ์)

รุ่น 7.8.0 (2026-10-13) สถาปนา Ecosystem 1.0: ผลิตภัณฑ์ทุกรายการที่แพ็กผสานรวมมาถึงรุ่นเสถียรรุ่นแรกและถูกตรึงไว้ที่ v1.0.0 ตามการกำหนดเวอร์ชันเชิงความหมาย (coding-agents-kit, herdr-peers, devcontainer-kit และ deepworkplan-vim แต่ละรายการมีไดเจสต์ `SHA256SUMS` ที่ผ่านการตรวจสอบ) ควบคู่กับการตรึง AI Diff Reviewer v3.3.14 และ Dailybot agent-skill v3.23.17 จากนั้น 7.8.1 (2026-10-14) ได้ตรึงรุ่นแพตช์ v1.0.1 ของ coding-agents-kit และ devcontainer-kit

รุ่น 7.9.0 (2026-10-25) ปักหมุดแอดออน Herdr ไว้ที่ herdr-peers v1.1.0 ซึ่งซับสกิลดีเบตแบบเนทีฟช่วยให้ lead จัดคณะ peer ให้ดำเนินไปหลายรอบและปิดท้ายด้วยบันทึกการตัดสินใจ และปักหมุด AI Diff Reviewer ไว้ที่ v3.3.16 ตอนนี้ CI ของแพ็กรันงาน Python 3.9 ขั้นต่ำบน ubuntu-24.04

รุ่น 7.10.0 (2026-10-26) เปลี่ยนการตัดสินใจที่มีน้ำหนักให้เป็นการตัดสินใจของทีม: เมื่อเปิดใช้แอดออน Herdr และใช้ herdr-peers 1.1.0 ขึ้นไป `create` จะวางแผนการตัดสินใจที่มีน้ำหนักแต่ละรายการ — สองทางเลือกที่ทำได้จริงซึ่งผลลัพธ์ต่างกันอย่างมีนัยสำคัญ ย้อนกลับได้ยากหรือครอบคลุมหลายส่วน และไม่มีอะไรในรีโปรตัดสิน — เป็นงานตัดสินใจที่ถูกลิสต์ไว้ และ `execute` จะดำเนินดีเบต `decide` ของ herdr-peers โดยไม่ออกเสียง บันทึกทุกที่นั่งลงในเจอร์นัลเป็นการมอบหมายแบบอ่านอย่างเดียว และบันทึกทางเลือกพร้อมบันทึกการตัดสินใจ ไม่มี Herdr ก็ไม่มีอะไรเปลี่ยน: ถ้าขาดเงื่อนไขเบื้องต้นหรือดีเบตล้มเหลวจะกลับไปที่บันทึกการตัดสินใจของเอเจนต์เอง และ `config.py decisions debate off` คืนสู่การตัดสินของเอเจนต์เดียว หมุดแอดออน Dailybot ย้ายไปที่ agent-skill v3.23.20 ซึ่งเป็นรุ่นที่ vendored ไว้

รุ่น 7.10.1 (2026-11-15) ปักหมุดแอดออน Herdr ไว้ที่ herdr-peers v1.2.1 ซึ่งสาย 1.2.x เพิ่ม autopilot: ดีมอนเสริมที่มนุษย์เท่านั้นเป็นผู้เริ่ม ยอมรับตัวเลือกที่แนะนำของทุกเอเจนต์ที่กำลังรอ ไล่บทสนทนาหลายขั้นจนจบ และไม่แตะการเข้าสู่ระบบหรือการยืนยันการข้ามสิทธิ์เลย โปรโตคอล 1 ไม่เปลี่ยนแปลง

รุ่น 7.10.2 (2026-11-15) ย้ายหมุดของระบบนิเวศตามการเปิดตัวของวันนี้: แอดออน Herdr ไปที่ herdr-peers v1.2.2 — แพตช์ที่มีแต่การแก้ไข autopilot ของมันตอบคำถามที่แสดงพร้อมตัวอย่างข้างตัวเลือกและจดจำเครื่องหมายแนะนำในภาษาสเปน ฝรั่งเศส เยอรมัน และอิตาลี; agentkit ไปที่ coding-agents-kit v1.2.0 ซึ่ง `ak last` ดำเนินเซสชันล่าสุดของไดเรกทอรีทำงานต่อในเทอร์มินัลใดก็ได้ และการเปิดภายใน pane ของ Herdr จะกู้คืน pane หลัง Herdr หรือเครื่องรีสตาร์ท; devcontainer-kit ไปที่ v1.1.2 และ deepworkplan-vim อยู่ที่ v1.0.1 เช่นเดิม; เวิร์กโฟลว์ release ตอนนี้ลองพุช release tag ซ้ำเพื่อดูดซับการปฏิเสธชั่วคราว

รุ่น 7.11.0 (2026-11-16) ลงมือกับชุดเสริมความแข็งแกร่ง v7 ของ developer: อภิธานความทนทานและกฎการควบคุมที่มองเห็นได้เข้าสู่คู่มือ, `verify` ได้การตรวจสอบการปฏิบัติตามแบบอ่านอย่างเดียวสำหรับแผนที่เสร็จแล้ว, เอกสารของแพ็กกล่าวถึงความทนทานและโทเคนอย่างแม่นยำ, สโลแกน README เปลี่ยนเป็นผู้ชนะการทดสอบความเข้าใจ, และเส้นทาง create แบบสดห่อ Lite ไว้ในงบคำสั่งของมัน

รุ่น 7.12.0 (2026-11-16) ลงทะเบียนแผนเข้ากับลูปของ herdr-peers: แผนจะเรียกร้องการเป็นผู้นำของมันพร้อมรายชื่อผู้สืบทอด ทำให้ `autopilot --loop` และ fleet UI เห็นทุกแผนที่เปิดอยู่และคงมันเดินจนจบ, และตัวแจ้งเตือน Dailybot รายงานหมุดหมาย; ดีสคริปเตอร์ของแอดออนย้ายไปที่ herdr-peers v1.3.1 และ coding-agents-kit v1.3.0.

รุ่น 7.12.1 (2026-11-16) แก้ไขตัวแจ้งเตือน Dailybot ของแอดออน Herdr: ตอนนี้ยอมรับชื่อเหตุการณ์ `herdr-peers/plan-event-v1` ที่ herdr-peers ปล่อยออกมา จำกัด stdin ของตัวแจ้งที่ 64 KiB และแมป `plan_lead_moved`; ดีสคริปเตอร์ของแอดออนย้ายไปที่ coding-agents-kit v1.4.0 ซึ่ง `ak update` ถูกบันทึกว่าเรียกใช้โดยมนุษย์เท่านั้น

รุ่น 7.12.2 (2026-11-16) ทำให้แอดออน Herdr ยอมรับโปรโตคอล 1 และ 2 ของ herdr-peers และปักหมุดไว้ที่ herdr-peers v2.0.0: เมื่อติดตั้งแบบโปรโตคอล 2 การตรวจหาจะไม่ล้มเหลวแบบเงียบอีกต่อไป และแอดออนยังคงความสามารถในการมอบหมายงานไว้

รุ่น 7.12.2 (2026-11-16) เป็นรุ่นสุดท้ายของ v7 และ v8 เป็นรุ่นที่สืบต่อมา.
