Deep Work Plan v7 คงวิธีการของ v6 ไว้ สัญญาคืออำนาจสูงสุด บันทึกแบบเพิ่มต่อท้ายอย่างเดียวคือหน่วยความจำ ตัวจัดตารางตัดสินว่าจะรันอะไรต่อไป และงานจะปิดได้ก็ต่อเมื่อหลักฐานที่บันทึกไว้ตรงตามเกณฑ์ของงานนั้น v7 เพิ่มความสามารถในการมอบหมายงาน และคงวินัยเดียวกันกับผลลัพธ์ที่ได้

แผนที่ให้สิทธิ์ `agent_delegation` สามารถทำเครื่องหมายงานเป็น `parallel_safe` แล้วส่งต่อให้เอเจนต์อื่นได้ คำตอบของผู้รับมอบหมายถูกบันทึกเป็นข้อมูล ไม่ใช่คำสั่ง และคงสถานะ `asserted` จนกว่าตัวรันเกตของแผนเองจะสังเกตเห็นผลลัพธ์ มีเพียงตัวรันเท่านั้นที่สร้างหลักฐาน `observed` ได้ การมอบหมายงานจึงขยายขอบเขตโดยไม่ลดมาตรฐานของการทำให้เสร็จ

แอดออนทางเลือกสี่รายการเปลี่ยนการมอบหมายงานให้เป็นความเป็นอิสระที่ใช้งานได้จริง Herdr ส่งงานให้เอเจนต์ในเพนบนเครื่องใดก็ได้ Agentkit วางคำสั่ง `ak` เพียงคำสั่งเดียวไว้เหนือเอเจนต์เขียนโค้ดบนเทอร์มินัลทั้งหมด โดยเปิดความเป็นอิสระเป็นค่าเริ่มต้นและปิดได้ และรันงานที่มีขอบเขตแบบไม่มีหน้าจอใน git worktree Devcontainer ให้แต่ละรีโพสิทอรีมีคอนเทนเนอร์ที่ทำซ้ำได้โดยไม่มีคีย์ SSH อยู่ภายในเป็นค่าเริ่มต้น (git ผ่าน SSH โดยใช้โฮสต์เอเจนต์ มีไฟล์คีย์เมื่อเลือกเปิดใช้งาน `[ssh] copy_keys` อย่างชัดเจนเท่านั้น) DeepWorkPlan Vim คือตัวแก้ไขบนเทอร์มินัลที่มีตัวเรียกดูแผนและตัวแสดง Markdown แต่ละรายการถูกตรึงด้วยแท็กกับผลิตภัณฑ์ที่มีรีโพสิทอรีของตนเอง และทำงานได้โดยไม่ต้องมี Deep Work Plan รีโพสิทอรีสอดคล้องครบถ้วนได้แม้ไม่ใช้รายการใดเลย และรีจิสทรีใน `.dwp/config.json` บันทึกว่าเปิดใช้รายการใดบ้าง

โหมดเบนช์มาร์กและบทเรียนบันทึกสิ่งที่แต่ละแผนสอนไว้ เพื่อให้วิเคราะห์ข้อค้นพบได้ภายหลัง การตรวจสอบระบบนิเวศทั้งหมด ซึ่งรันเป็นแผนผู้ประสานงาน v7 โดยใช้หนึ่งเอเจนต์ต่อหนึ่งรีโพสิทอรี ไม่พบการถดถอยด้านพฤติกรรมเมื่อเทียบกับ v6 ชุดทดสอบของแพ็กผ่าน 807 จาก 807 ในสภาพแวดล้อมที่สะอาด และปริมาณคำสั่งเพิ่มขึ้น 0.1% ถึง 3.9% ต่อโฟลว์ (4.6% สำหรับทั้งแพ็ก) วัดเป็นไบต์บนทั้งสองแท็ก ไม่ได้ประมาณเป็นโทเค็น

v7 เป็นก้าวสำคัญด้านการประสานงานและความสามารถในการตรวจสอบ แต่ยังไม่ใช่ความเป็นอิสระที่ไม่ต้องมีคนดูแลเลย รุ่น 7.2.0 ปิดช่องว่างที่การตรวจสอบนั้นพบ: เบนช์มาร์กและบทเรียนตอนนี้วัดแผน v7 ได้ การเริ่มงานก่อนที่ข้อกำหนดเบื้องต้นจะเสร็จสมบูรณ์จะถูกปฏิเสธ และชุดทดสอบทำงานแบบปิดผนึก (815 จาก 815 ในสภาพแวดล้อมที่สะอาด) ยังไม่ได้วัดว่าผลลัพธ์ของเอเจนต์ไม่ด้อยกว่าเดิม แผนเดิมคงรุ่นที่บันทึกไว้และจะไม่ถูกย้ายโดยปริยาย แผนใหม่ใช้สัญญา v7 เป็นค่าเริ่มต้น

รุ่น 7.6.0 (2026-10-11) แนะนำการประสานงานขนาดใหญ่: เลน (lanes), การทำงานแบบหลายบัญชี (`ak capacity`), การเปิดตัวแบบอัตโนมัติ และการเริ่มต้นใช้งานแอดออนทั้งหมดที่ตรวจพบเครื่องมือที่มีอยู่พร้อมเสนอการอัปเกรด

รุ่น 7.7.0 (2026-10-12) มอบความเป็นอิสระแบบกลุ่ม (คู่มือ §17): ลูปความจุ (`shared/swarm.py`), แพ็กเก็ตการส่งต่องาน (`dwp-handoff-v1`), การสืบทอดตำแหน่งผู้นำพร้อมรอบยุคและการแยกส่วน, การร้องขอข้ามเลน, การจัดหมวดหมู่การยกระดับปัญหาตาม AGENT_PROTOCOL §7.5 (C1–C7: ตัดสินใจและบันทึกสิ่งอื่นทั้งหมด), มาตรฐานคุณภาพ (เกตคือสมมติฐาน ได้รับการตรวจสอบแล้วไม่ใช่แค่การอ้างสิทธิ์) และบทเรียนระเบียบวิธีจากแผนที่ดำเนินการแล้ว 313 แผนใน 23 รีโพสิทอรี ขีดจำกัดที่ทราบ (LEAD-12): เจอร์นัล v7 ไม่มีเหตุการณ์เฉพาะสำหรับการส่งต่อเลนหรือการสืบทอดตำแหน่งผู้นำ (บันทึกเป็นการมอบหมายที่ถูกยกเลิกบวกกับการสังเกตการณ์)

รุ่น 7.8.0 (2026-10-13) สถาปนา Ecosystem 1.0: ผลิตภัณฑ์ทุกรายการที่รวมอยู่ในแพ็กมาถึงรุ่น semver เสถียรรุ่นแรก (coding-agents-kit v1.0.0, herdr-peers v1.0.0, devcontainer-kit v1.0.0, deepworkplan-vim v1.0.0, ai-diff-reviewer v3.3.14 และ Dailybot agent-skill v3.23.17) พร้อมผลสรุปการเผยแพร่ SHA256SUMS ที่ผ่านการตรวจสอบ ตามด้วย 7.8.1 (2026-10-14) ซึ่งตรึงรุ่นแพตช์ 1.0.1

รุ่น skill ที่ติดตั้งคือ **7.8.1** เสถียรตั้งแต่ 7.0.0
