## Что это такое

Конфигурация Neovim для людей и программистских агентов, живущих в терминале — ваши Deep Work Plans, документация и индекс команд на расстоянии одного нажатия клавиши.

## Установка

Одна строка устанавливает DeepWorkPlan Vim как вашу конфигурацию Neovim. Установщик объясняет, что сделает, и спрашивает, прежде чем трогать существующую настройку.

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

Сначала согласие: существующая конфигурация Neovim никогда не перезаписывается без вашего явного одобрения. Установщик останавливается и показывает ручной путь.

В Windows однострочник не применяется; ручной путь описан в README репозитория. [Путь установки для Windows](https://github.com/DailybotHQ/deepworkplan-vim#install-host)

## Что он делает

Пять возможностей, сознательно ограниченных по охвату. Каждая соответствует сочетанию клавиш, которое можно посмотреть в генерируемом индексе команд.

| Возможность | Что это | Привязка |
|---|---|---|
| Генерируемый индекс команд | Индекс команд генерируется из действующей конфигурации, поэтому список привязок клавиш всегда актуален. | `SPC h h` |
| Жесты в духе VS Code | Жесты редактирования, знакомые по графическим редакторам: выделить всё и скопировать в системный буфер обмена. | `<C-a>`, `y`, `<leader>y` |
| Обозреватель Deep Work Plan | Панель для просмотра планов репозитория — читайте план, его задачи и его ворота валидации, не покидая редактор. | `SPC P` |
| Просмотрщик Markdown | Предпросмотр Markdown в браузере или рендер в буфере — документация и планы остаются там, где идёт работа. | `SPC m p`, `SPC m r` |
| Установщик одной строкой | Самодостаточный установщик для macOS и Linux с документированным ручным путём для Windows. | — |

## Требования

- Neovim 0.12 или новее, с доступной Lua (lua, lua5.4 или luajit)
- macOS и Linux; Windows поддерживается через документированный ручной путь
- Лицензия GPL-3.0 — свободно использовать, изучать и изменять
