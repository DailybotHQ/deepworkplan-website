## Що це таке

Конфігурація Neovim для людей і програмістських агентів, які живуть у терміналі — ваші Deep Work Plans, документація та індекс команд на відстані одного натискання клавіші.

## Встановлення

Один рядок встановлює DeepWorkPlan Vim як вашу конфігурацію Neovim. Інсталятор пояснює, що зробить, і питає, перш ніж торкатися наявного налаштування.

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

Спочатку згода: наявну конфігурацію Neovim ніколи не перезаписують без вашого явного схвалення. Інсталятор зупиняється і показує ручний шлях.

У Windows однорядковик не застосовується; ручний шлях описано в README репозиторію. [Шлях встановлення для Windows](https://github.com/DailybotHQ/deepworkplan-vim#install-host)

## Що він робить

Пʼять можливостей, свідомо обмежених за охопленням. Кожна відповідає поєднанню клавіш, яке можна переглянути в генерованому індексі команд.

| Можливість | Що це | Привʼязка |
|---|---|---|
| Генерований індекс команд | Індекс команд генерується з чинної конфігурації, тож список привʼязок клавіш завжди актуальний. | `SPC h h` |
| Жести в дусі VS Code | Жести редагування, знайомі за графічними редакторами: виділити все та скопіювати в системний буфер обміну. | `<C-a>`, `y`, `<leader>y` |
| Оглядач Deep Work Plan | Панель для перегляду планів репозиторію — читайте план, його завдання та його ворота валідації, не виходячи з редактора. | `SPC P` |
| Переглядач Markdown | Попередній перегляд Markdown у браузері чи рендер у буфері — документація та плани лишаються там, де триває робота. | `SPC m p`, `SPC m r` |
| Інсталятор одним рядком | Самодостатній інсталятор для macOS і Linux з документованим ручним шляхом для Windows. | — |

## Вимоги

- Neovim 0.12 або новіший, з доступною Lua (lua, lua5.4 або luajit)
- macOS і Linux; Windows підтримується через документований ручний шлях
