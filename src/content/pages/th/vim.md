## คืออะไร

คอนฟิกูเรชัน Neovim สำหรับมนุษย์และเอเจนต์เขียนโค้ดที่อาศัยอยู่ในเทอร์มินัล — Deep Work Plans เอกสาร และดัชนีคำสั่งของคุณ อยู่ห่างเพียงการกดคีย์เดียว

## การติดตั้ง

หนึ่งบรรทัดติดตั้ง DeepWorkPlan Vim เป็นคอนฟิกูเรชัน Neovim ของคุณ ตัวติดตั้งจะอธิบายว่าจะทำอะไร และถามก่อนแตะต้องการตั้งค่าที่มีอยู่

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

ขอความยินยอมก่อน: คอนฟิกูเรชัน Neovim ที่มีอยู่จะไม่ถูกเขียนทับเด็ดขาดหากไม่ได้รับอนุมัติอย่างชัดเจนจากคุณ ตัวติดตั้งจะหยุดและแสดงวิธีแบบแมนนวลแทน

บน Windows คำสั่งบรรทัดเดียวใช้ไม่ได้ วิธีแบบแมนนวลมีอธิบายไว้ใน README ของ repository [วิธีติดตั้งบน Windows](https://github.com/DailybotHQ/deepworkplan-vim#install-host)

## มันทำอะไร

ห้าฟีเจอร์ ที่จงใจจำกัดขอบเขต แต่ละฟีเจอร์มีคีย์ไบน์ดิงกำกับ ซึ่งคุณตรวจสอบได้ในดัชนีคำสั่งแบบสร้างอัตโนมัติ

| ฟีเจอร์ | คืออะไร | การผูกคีย์ |
|---|---|---|
| ดัชนีคำสั่งแบบสร้างอัตโนมัติ | ดัชนีคำสั่งสร้างจากคอนฟิกูเรชันที่ใช้งานจริง รายการคีย์ไบน์ดิงจึงเป็นปัจจุบันเสมอ | `SPC h h` |
| ท่าทางแบบ VS Code | ท่าทางการแก้ไขที่เลียนแบบเอดิเตอร์กราฟิกกาล: เลือกทั้งหมด และคัดลอกไปยังคลิปบอร์ดของระบบ | `<C-a>`, `y`, `<leader>y` |
| ตัวเรียกดู Deep Work Plan | แผงสำหรับเรียกดูแผนใน repository — อ่านแผน งานต่าง ๆ และเกตตรวจสอบความถูกต้อง โดยไม่ต้องออกจากเอดิเตอร์ | `SPC P` |
| ตัวดู Markdown | ดูตัวอย่าง Markdown ในเบราว์เซอร์ หรือเรนเดอร์ในบัฟเฟอร์ — เอกสารและแผนอยู่ที่ซึ่งงานเกิดขึ้น | `SPC m p`, `SPC m r` |
| ตัวติดตั้งหนึ่งบรรทัด | ตัวติดตั้งที่สมบูรณ์ในตัวสำหรับ macOS และ Linux พร้อมวิธีแบบแมนนวลที่บันทึกไว้สำหรับ Windows | — |

## ข้อกำหนด

- Neovim 0.12 หรือใหม่กว่า พร้อม Lua (lua, lua5.4 หรือ luajit) ที่พร้อมใช้
- macOS และ Linux; Windows รองรับผ่านวิธีแบบแมนนวลที่บันทึกไว้
- สัญญาอนุญาต GPL-3.0 — ใช้งาน ศึกษา และแก้ไขได้อย่างเสรี
