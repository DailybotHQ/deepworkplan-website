## यह क्या है

टर्मिनल में काम करने वाले लोगों और कोडिंग एजेंटों के लिए Neovim कॉन्फ़िगरेशन — आपके Deep Work Plans, दस्तावेज़ और कमांड इंडेक्स एक कीस्ट्रोक की दूरी पर।

## इंस्टॉलेशन

एक पंक्ति DeepWorkPlan Vim को आपके Neovim कॉन्फ़िगरेशन के रूप में इंस्टॉल करती है। इंस्टॉलर बताता है कि वह क्या करेगा, और मौजूदा सेटअप को छूने से पहले पूछता है।

```bash
curl -fsSL https://deepworkplan.com/vim/install.sh | bash
```

पहले सहमति: मौजूदा Neovim कॉन्फ़िगरेशन को आपकी स्पष्ट स्वीकृति के बिना कभी ओवरराइट नहीं किया जाता। इंस्टॉलर रुक जाता है और मैन्युअल मार्ग दिखाता है।

Windows पर एक-पंक्ति वाला कमांड लागू नहीं होता; मैन्युअल मार्ग रिपॉज़िटरी के README में प्रलेखित है। [Windows इंस्टॉलेशन मार्ग](https://github.com/DailybotHQ/deepworkplan-vim#install-host)

## यह क्या करता है

पाँच सुविधाएँ, जानबूझकर सीमित दायरे में। हर सुविधा एक कीबाइंडिंग से जुड़ी है, जिसे आप जनरेट किए गए कमांड इंडेक्स में देख सकते हैं।

| सुविधा | यह क्या है | मैपिंग |
|---|---|---|
| जनरेट किया गया कमांड इंडेक्स | कमांड इंडेक्स सक्रिय कॉन्फ़िगरेशन से जनरेट होता है, इसलिए कीबाइंडिंग की सूची हमेशा अद्यतित रहती है। | `SPC h h` |
| VS Code शैली के जेस्चर | ग्राफ़िकल एडिटरों से आकार लिए एडिटिंग जेस्चर: सब चुनें, और सिस्टम क्लिपबोर्ड पर कॉपी करें। | `<C-a>`, `y`, `<leader>y` |
| Deep Work Plan ब्राउज़र | रिपॉज़िटरी के प्लान ब्राउज़ करने वाला पैनल — एडिटर छोड़े बिना प्लान, उसके कार्य और उनके वैलिडेशन गेट पढ़ें। | `SPC P` |
| Markdown व्यूअर | Markdown का ब्राउज़र में प्रीव्यू लें या बफ़र में रेंडर करें — दस्तावेज़ और प्लान वहीं रहते हैं जहाँ काम होता है। | `SPC m p`, `SPC m r` |
| एक-पंक्ति इंस्टॉलर | macOS और Linux के लिए आत्मनिर्भर इंस्टॉलर, Windows के लिए प्रलेखित मैन्युअल मार्ग के साथ। | — |
